# 氣運復仇者 / QiYun Avengers

> 短局制 2D Roguelite 復仇動作遊戲：你不是被命運選中的英雄，而是所有被英雄踩過去的反派怨念集合體。

## 一句話定位

玩家操控由敗者怨念凝聚而成的 **Ghost**，在一局局 2D 戰鬥中擊敗「被世界偏愛的英雄」，奪取他們的招牌能力，再利用能力相剋反過來獵殺下一位英雄。

## 核心角色

- **Ghost**：玩家角色。所有被打敗反派留下的怨念集合體；可愛、陰森、不是傳統救世主。
- **M先生**：正義側英雄。紅帽、維修工氣質的原創 Q 版積木人物。
- **U-man**：正義側英雄。白色主體、紅色對稱紋樣、白色橢圓眼、藍色胸口寶石、紅色大腿。
- **滅影忍者／吾空／失敗的面／消炎／葫蘆爺／鋼筋戰士**：後續 Boss 池，詳見 `docs/04_BOSS_AND_MINIONS.md`。

## 核心設計原則

1. **一局要短，決策要清楚。** 不堆大型 RPG 系統。
2. **打贏英雄 = 拿到新玩法。** 能力奪取必須直接改變下一場戰鬥方式。
3. **相剋重於數值碾壓。** 玩家學的是英雄能力與弱點，不是單純刷攻擊力。
4. **失敗要能推進理解。** Roguelite 重開後，玩家對英雄與能力組合的判斷會更準。
5. **美術要有自己的辨識度。** 採原創圓潤 Q 版積木人物語言，不使用任何可辨識為既有拼裝玩具品牌的造型特徵。

## 非目標

此階段明確不做：

- 開放世界
- 3A 規模角色養成與內容量
- 大量 NPC 附身系統
- 龐大分支劇情樹
- 為了「內容很多」而加入與核心戰鬥無關的系統

## 下一階段

完成基礎企劃後，下一個可實作里程碑應是 **Vertical Slice**：

`Ghost + 教學地圖 + 3 位英雄完整關卡 + 每張正式地圖 30～50 名正派小角色 + 3 種可奪取能力 + 明確相剋小環`

目標是先證明「教學 → 完整小怪區 → Boss 戰 → 奪能力 → 用能力剋下一位英雄」真的好玩。MVP 是少做幾張完整地圖，不是把每張正式地圖縮成展示房；1～3 每張英雄地圖都必須有 30～50 名正派小角色、固定 3 種小角色、8～12 波配置、Boss 前補給點或弱點提示。
