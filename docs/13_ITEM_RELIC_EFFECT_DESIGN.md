# 13｜道具、遺物與效果設計 V1

專案：《氣運復仇者》 / QiYun Avengers

用途：固定局內道具、被動遺物、消耗品、詛咒道具、商店商品、掉落規則與效果命名方向，支援 Roguelite Build，但不壓過「Boss 能力奪取」的核心。

> 遺物不是主角，Boss 技能才是主角。
>
> 遺物的功能是讓 Boss 技能長出不同玩法，而不是用一堆 +5% 淹沒遊戲。🎲

---

## 0. 道具與遺物總原則

### 0.1 設計目的

道具與遺物要完成五件事：

1. 讓每局 Build 不一樣。
2. 強化 Boss 技能的玩法差異。
3. 製造風險與取捨。
4. 支援黑色幽默世界觀。
5. 給玩家短期目標與驚喜。

### 0.2 不做什麼

不優先做：

- 幾十種只加小數值的裝備。
- 複雜裝備欄、重量、耐久。
- 長篇裝備敘事。
- 需要玩家反覆比較 2% 差異的刷裝。
- 和 Boss 技能無關的獨立大系統。

## 1. 分類

| 類型 | 說明 | 是否跨局保留 |
|---|---|---|
| 消耗品 | 當場使用或撿到即觸發 | 否 |
| 遺物 | 當局被動效果 | 否 |
| 詛咒遺物 | 強力被動，但有代價 | 否 |
| 商店商品 | 金幣購買的技能、補給或遺物 | 否 |
| Boss 戰利品 | 擊敗 Boss 後固定掉落能力 | 可解鎖 / 可記錄 |
| 圖鑑記錄 | 看過、拿過、被害過的內容 | 是 |
| 外觀收藏 | 長期收藏，不影響平衡 | 是，可後續做 |

## 2. 效果標籤系統

遺物效果應該使用和技能相同的標籤，方便聯動。

| 標籤 | 對應玩法 |
|---|---|
| `impact` | 震波、擊退、破隱 |
| `shadow` | 閃避、背刺、穿越 |
| `core` | 光束、穿盾、蓄力 |
| `armor_break` | 多段、破甲、打斷 |
| `devour` | 吸收、反吐、投射物處理 |
| `flame` | 持續傷害、禁療、蔓延 |
| `web` | 牽引、束縛、控制位置 |
| `ki` | 霸體、近戰、低血爆發 |
| `luck` | 氣運、暴擊、掉落、逆轉 |
| `curse` | 代價、詛咒、風險收益 |
| `economy` | 金幣、商店、折扣 |
| `survival` | 回血、護盾、保命 |
| `erase` | 清除、封鎖、Creator 干涉 |

## 3. 稀有度

| 稀有度 | 顏色方向 | 效果定位 |
|---|---|---|
| Common | 灰白 / 淡紫 | 小幅穩定強化。 |
| Rare | 藍紫 | 新增明確功能。 |
| Epic | 金紫 | 形成 Build 聯動。 |
| Legendary | 黑金 | 改變玩法核心。 |
| Cursed | 紅黑 | 強力但有代價。 |
| Joke | 粉紫 / 可愛怪 | 黑色幽默或特殊事件，不一定強。 |

稀有度不只代表強度，也代表玩家看到時的情緒：

```text
Common：可以用。
Rare：這局有方向了。
Epic：Build 開始成形。
Legendary：這局可能要改打法。
Cursed：很香，但你確定嗎？
Joke：笑一下，然後可能真的有用。
```

## 7. 經濟與商店道具

### 7.1 貨幣

建議貨幣名稱：

```text
怨幣
```

來源：

- 小怪掉落。
- 精英戰獎勵。
- 事件交換。
- 遺物效果。
- 打破場景物件。

用途：

- 商店買遺物。
- 買補給。
- 移除詛咒。
- 重骰三選一。
- 解鎖一次性特殊事件。

### 7.2 商店商品

| 商品 | 功能 |
|---|---|
| 破碎飯糰 | 回血。 |
| 小怨念糖 | 回怨念。 |
| 隨機 Common 遺物 | 便宜。 |
| 隨機 Rare 遺物 | 中價。 |
| 技能升級券 | 立即升級一個已裝備技能。 |
| 重骰券 | 下一次三選一可重骰。 |
| 詛咒清潔服務 | 移除一個 Cursed 遺物或降低代價。 |
| 神秘垃圾桶 | 隨機給一個遺物，也可能給詛咒。 |

### 7.3 商店黑色幽默文案

```text
「英雄有贊助商，反派只能自己付錢。」
「本店不保證能活著離開，但保證收款成功。」
「買不起？那你可能比較適合當經驗值。」
```

## 9. 掉落規則

### 9.1 小怪掉落

小怪不應掉太多東西，避免畫面亂。

| 掉落 | 機率方向 |
|---|---|
| 怨幣 | 常見 |
| 小怨念糖 | 偶爾 |
| 破碎飯糰 | 少量 |
| Common 遺物 | 稀有 |
| 事件鑰匙 | 特定房間 |

### 9.2 精英掉落

精英戰應給比較明確的 Build 推進：

- 三選一升級。
- Rare 以上遺物機率提高。
- 可選擇怨幣或遺物。
- 有概率掉詛咒遺物。

### 9.3 Boss 掉落

Boss 掉落應固定：

```text
Boss 招牌能力 + 1 次技能升級 / 遺物選擇
```

Boss 技能不能靠隨機掉落，否則核心體驗會失焦。

## 10. 遺物與氣運壓力

部分強力遺物會提高氣運壓力。

| 行為 | 可能影響 |
|---|---|
| 拿 Cursed 遺物 | 氣運壓力上升。 |
| 連續購買神秘商品 | 氣運壓力上升。 |
| 使用假主角光環 | 氣運壓力上升。 |
| 擊敗精英但不拿獎勵 | 氣運壓力下降或穩定。 |
| 犧牲遺物換取安全 | 氣運壓力下降。 |

氣運壓力要可視化，例如：

- 畫面邊緣出現金白裂光。
- Boss 台詞變得自信。
- 小怪開始喊支援。
- UI 上的命運指針偏向英雄側。

## 11. 負面效果與詛咒

### 11.1 詛咒類型

| 詛咒 | 效果 |
|---|---|
| 技能冷卻增加 | 強迫玩家改節奏。 |
| 最大 HP 暫降 | 增加生存壓力。 |
| 商店漲價 | 經濟壓力。 |
| 小怪增援 | 戰鬥壓力。 |
| Boss 開場護盾 | Boss 壓力。 |
| 三選一少一個 | Build 壓力。 |
| 氣運反撲提前 | 戲劇壓力。 |

### 11.2 詛咒設計原則

- 詛咒必須事先說清楚。
- 詛咒不能直接讓玩家無解死亡。
- 詛咒要能形成有趣選擇。
- 詛咒可以很壞，但不能偷偷壞。

```text
是否可被 Creator / Eraser 影響
```

範例：

```text

標籤：luck / cooldown
短效果：Boss 進入氣運反撲時，Ghost 技能冷卻全部縮短。
吐槽：既然劇本不站你這邊，那就偷看下一頁。
```

## 17. 平衡原則

### 17.1 遺物強度限制

遺物不能比 Boss 技能更重要。

檢查方式：

```text
如果拿掉 Boss 技能，只靠遺物也能形成完整主要玩法，代表遺物太強或技能太弱。
```

### 17.2 疊加限制

| 類型 | 疊加方式 |
|---|---|
| 小數值 | 可疊，但遞減。 |
| 功能改造 | 通常不可疊。 |
| 保命 | 嚴格限制，避免不死。 |
| 經濟 | 可疊但要防止爆錢。 |
| 詛咒 | 可多個存在，但需 UI 清楚。 |

### 17.3 掉落節奏

每局前期給方向，中期給組合，後期給爆點。

```text
前期：Common / Rare，讓玩家選流派。
中期：Rare / Epic，讓 Build 成形。
後期：Epic / Legendary / Cursed，讓局勢爆炸。
```

## 18. 驗收清單

道具與遺物系統完成後檢查：

- 是否支援 Boss 技能，而不是取代 Boss 技能？
- 是否至少有 3 種不同 Build 原型？
- 是否有足夠黑色幽默文案？
- 是否每個稀有度都有明確情緒？
- 是否有消耗品、被動、詛咒、商店商品？
- 是否避免過多 +5% 類無聊效果？
- 是否每個強力遺物都有代價、冷卻或限制？
- 是否能用 icon 一眼看懂功能？
- 是否和技能標籤系統相容？
- 是否能被 Creator / Eraser 在終局中干涉或反制？
