# 01｜遊戲簡介

## 專案名稱

**《氣運復仇者》 / QiYun Avengers**

## 一句話定位

一款短局制 2D Roguelite 復仇動作遊戲：玩家操控由所有敗者怨念凝聚而成的 Ghost，獵殺被世界偏愛的英雄、奪走他們的能力，再把「英雄的力量」變成下一場復仇的武器。

## 世界觀核心

這個世界的英雄總能在最危險的時候得到奇蹟、覺醒、援軍、神器或命運眷顧。

故事通常只會記得「英雄如何逆轉勝」。

但每一次英雄的勝利，都意味著另一群角色被踩在腳下：被秒殺的反派、被劇情犧牲的小頭目、永遠差一點成功的宿敵、只是站錯邊就被當成經驗值的人。

那些失敗者留下的怨念沒有消失，而是逐漸凝聚成一個新的存在：**Ghost**。

Ghost 不是某一位反派復活，也不是新的天選之子。它是「所有輸家不甘心的殘響」。

它唯一清楚的本能就是：

> 既然世界永遠把氣運給英雄，那就把英雄身上的氣運一個一個搶回來。

## 玩家扮演什麼

玩家扮演 **Ghost**。

Ghost 的初始能力有限，但它擁有一項最關鍵的特性：

**擊敗英雄後，可以奪取對方的招牌能力。**

因此每擊敗一名英雄，玩家不只是數值變強，而是得到一個新的戰鬥工具、新的移動方式或新的克制手段。

## 玩家實際在做什麼

一局遊戲的體驗可以濃縮為：

1. 進入一條短關卡。
2. 遭遇雜兵、陷阱或英雄勢力的防線。
3. 蒐集少量局內強化，建立這一局的戰鬥節奏。
4. 挑戰英雄 Boss。
5. 擊敗 Boss 後奪取其招牌能力。
6. 根據下一位英雄的特性，決定能力使用與攻略順序。
7. 利用「能力相剋」打出明顯優勢。
8. 持續獵殺英雄，直到本局終點或 Ghost 被擊敗。
9. 重開後保留玩家對英雄、能力、風險與路線的理解，再形成新的能力組合。

## 核心爽點

### 1. 把英雄的招牌招式搶過來

玩家最大的成長回饋不是「攻擊力 +5%」，而是：

**剛剛還把我打爆的那招，現在變成我的。**

這讓 Boss 戰本身同時也是下一階段玩法的解鎖過程。

### 2. 反過來用英雄能力剋英雄

能力之間存在清楚、可理解、可預判的相剋關係。

理想狀態不是「某個能力傷害最高」，而是：

- 某英雄的護盾怕穿透或震擊。
- 某英雄依賴高速位移，卻怕定身或範圍封鎖。
- 某英雄蓄力時很強，但可被特定能力打斷。

玩家找到正確相剋時，會有「我破解你了」的爽感。

### 3. 從被氣運壓著打，到反過來拆英雄套路

前期 Ghost 是弱者；中後期玩家開始理解每個英雄的招牌套路，並用上一位英雄的能力去破解下一位。

這種「從被劇情殺，到開始反殺主角團」是整個專案最重要的情緒曲線。

## 情緒與敘事語氣

基調不是純黑暗復仇，也不是嚴肅悲劇。

更接近：

- 黑色幽默
- 反英雄敘事
- 對「主角光環」與「氣運」的戲謔
- 可愛外型包裹偏陰暗的世界觀

Ghost 可以很可愛，但它做的事情不是可愛冒險；英雄看起來光明正義，但遊戲會從被他們打敗的人視角重新解讀這些勝利。

## 主要角色

### Ghost

玩家主角。

- 身分：所有敗者怨念的集合體。
- 外型：黑紫色斗篷、發光點狀眼睛、圓潤饅頭手。
- 氣質：可愛、安靜、詭異、帶一點報復性的執著。
- 功能定位：透過奪取能力不斷改變玩法。

### M先生

正義側英雄之一。

- 紅帽。
- 維修工／工程工人式輪廓語言。
- 原創 Q 版積木人物比例。
- 不使用任何既有知名遊戲角色或拼裝玩具的辨識性造型語彙。

M先生適合作為早期英雄之一：造型易讀、能力可做成直觀的近戰／工具型機制，方便玩家第一次理解「擊敗 → 奪取能力」。

### U-man

正義側英雄之一。

固定視覺特徵：

- 白色身體主體。
- 粗而對稱的紅色紋樣。
- 白色橢圓眼。
- 藍色胸口寶石。
- 純紅色大腿。

U-man 適合作為比 M先生更具壓迫感的中高階英雄，能力可偏能量、衝刺或光束類，形成不同戰鬥節奏。

## 它不是什麼

《氣運復仇者》不是：

- 開放世界探索遊戲。
- 需要幾十小時主線才能體驗核心玩法的 RPG。
- 靠巨大技能樹堆疊數值的養成遊戲。
- 以複雜 NPC 對話與分支劇情為主的敘事遊戲。
- 需要大量 3D 資產與電影式過場的 3A 專案。

如果某個新系統不能直接強化「打英雄 → 搶能力 → 相剋下一位英雄」這條主循環，就不應優先加入 MVP。

## 產品型態

優先產品型態：

- 2D 橫向或固定戰鬥區域動作遊戲。
- 單人。
- 短局制。
- Roguelite 重玩結構。
- PC / Web Prototype 優先驗證玩法，後續再視操作與效能決定其他平台。

## 最小可行版本（MVP）

MVP 不追求英雄數量，而是先證明核心爽點。

建議內容：

- Ghost 1 名。
- 英雄 2 名：M先生、U-man。
- 每名英雄 1 個可奪取招牌能力。
- 至少 1 組明顯能力相剋。
- 1 條可在 10～20 分鐘內跑完的短流程。
- 失敗後可立即重新開始。
- 有最基本的局內隨機變化，確保第二局不是完全照抄第一局。

## 成功驗證標準

Vertical Slice 完成後，優先驗證三件事：

1. 玩家打完 Boss 後，是否真的期待「把他的能力拿來用」。
2. 玩家是否能自行發現或學會能力相剋，而不是只看傷害數字。
3. 重開一局時，玩家是否會想嘗試不同英雄順序或能力組合。

只要這三件事成立，才值得繼續擴充更多英雄、更多能力與更完整的 Roguelite 結構。
