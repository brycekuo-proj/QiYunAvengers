## 0. 敘事總原則

### 0.1 語氣定位

《氣運復仇者》的文字語氣是：

- 黑色幽默。
- 反英雄。
- 可愛外皮下有怨念。
- 嘲諷「主角光環」與「世界偏心」。
- 不做過度沉重的悲劇長篇。
- 不用血腥、殘酷虐殺當賣點。

### 0.2 文案長度原則

| 場景 | 建議字數 |
|---|---:|
| 戰鬥中 Boss 台詞 | 6～18 字 |
| 關卡開場旁白 | 40～120 字 |
| Boss 初登場 | 40～100 字 |
| 死亡結算句 | 10～30 字 |
| 道具吐槽 | 10～25 字 |
| 圖鑑描述 | 80～180 字 |
| 結局文字 | 300～800 字 |

動作遊戲不適合在戰鬥前塞太多文字。大段敘事可放圖鑑、幕間、結算或收藏頁。

## 1. 故事主軸

### 1.1 世界觀

這個世界裡，英雄總會在最危險的時候得到奇蹟。

當英雄快輸時，會有人伸手；當英雄受傷時，會有人犧牲；當英雄需要力量時，神器會剛好出現；當英雄犯錯時，世界會幫他們解釋成成長。

但每一次英雄勝利，都會留下被踩過去的人。

那些人沒有名字，沒有續集，沒有紀念碑。他們只是劇情裡的經驗值、反派部下、失敗宿敵、路邊小怪、被拯救世界時順便打碎的背景。

直到所有不甘心聚在一起，變成了 Ghost。

### 1.2 Ghost 的目標

Ghost 不想拯救世界，也不想統治世界。

Ghost 只想做一件事：

```text
把英雄身上的氣運，一個一個搶回來。
```

### 1.3 遊戲敘事節奏

```text
甦醒：Ghost 從失敗者怨念中誕生。
  ↓
復仇：Ghost 開始獵殺被世界偏愛的英雄。
  ↓
學習：Ghost 發現每個英雄都有被世界保護的套路。
  ↓
奪取：Ghost 把英雄能力變成自己的武器。
  ↓
反轉：Ghost 不再只是被劇情殺的輸家，而開始拆解劇本。
  ↓
真相：Creator 是英雄們背後的創作者與規則源頭。
  ↓
選擇：Ghost 是要刪掉英雄，還是刪掉「只有英雄值得被記住」的規則。
```

## 2. 角色語氣

### 2.1 Ghost

Ghost 可以不常說話。

它的語氣可以是：

- 短句。
- 安靜。
- 冷幽默。
- 有時像小孩，有時像很多人的重疊聲。
- 不喊熱血口號。

Ghost 台詞範例：

```text
「輪到我了。」
「這招，我收下。」
「你也會怕輸嗎？」
「原來英雄也會倒地。」
「不是正義贏了，是你們比較被偏愛。」
```

### 2.2 旁白

旁白像一本壞掉的英雄史書，偶爾冷淡、偶爾嘲諷。

旁白範例：

```text
英雄故事通常從光開始。
可惜你不是光。
你是光照不到的那一團東西。
```

```text
世界很公平。
它公平地把所有奇蹟都分給英雄。
```

### 2.3 Boss

Boss 要相信自己是正義的。

他們不是故意邪惡，而是習慣被世界支持，習慣認為自己贏是理所當然。

Boss 台詞風格：

- 自信。
- 熱血。
- 教訓玩家。
- 被破防時出現慌張。
- 死前才意識到「自己也可能是被打倒的人」。

## 3. 關卡開場文案

### 3.1 地圖 0：怨念甦醒地

```text
沒有墓碑，沒有名字，沒有故事。
只有一堆被英雄勝利順手碾過的失敗者，沉在世界邊角。

某一天，它們終於不想安靜了。
```

### 3.2 地圖 1：紅帽管線城

```text
這座城市到處都是跳台、管線與歡呼聲。
每個人都說，那位紅帽英雄修好了世界。

沒有人提到，被他踩碎的那些東西原本也有自己的路。
```

### 3.3 地圖 2：影村訓練場

```text
忍者村教孩子們隱身、分身、背刺，然後把這些稱為守護。

Ghost 不太懂守護。
它只知道，被背刺的人通常沒有台詞。
```

### 3.4 地圖 3：藍核防衛基地

```text
光照亮基地時，所有人都抬頭歡呼。

Ghost 躲在陰影裡，看見光束穿過地面，順便也穿過了那些沒被鏡頭拍到的人。
```

### 3.5 地圖 4：鋼筋戰隊工廠

```text
他們說團隊就是力量。
五種顏色站在一起，連爆炸都顯得很正義。

但被圍毆的那一方，通常不覺得這叫友情。
```

### 3.6 地圖 5：七色葫蘆山

```text
葫蘆會收妖，會吐火，會把不聽話的東西裝進去。

山下的人說這是法寶。
被裝進去的人說不出話。
```

### 3.7 地圖 6：異火煉藥宗

```text
奇遇、丹藥、異火、師承。
英雄把每一份偏心都叫作努力。

Ghost 聽完，默默把藥爐推近了一點。
```

### 3.8 地圖 7：蛛網都市天台

```text
城市需要英雄。
需要一個在高樓之間擺盪的人，告訴大家正義還在。

至於被蛛線拉進危險裡的人，新聞通常剪掉。
```

### 3.9 地圖 8：鬥氣武道星

```text
強者說要保護弱者。
但弱者要先證明自己值得被保護。

Ghost 沒有證明。
它只帶了一雙小拳頭。
```

### 3.10 地圖 9：命運劇場

```text
所有英雄故事都在這裡排練。
失敗者負責倒下，英雄負責站起來，觀眾負責鼓掌。

今天，有個不在劇本上的東西進場了。
```

## 4. Boss 初登場文案

### 4.1 M先生

```text
M先生舉起水管，帽沿下的眼神充滿正義。

「放心，我很擅長修理壞掉的東西。」

Ghost 低頭看了看自己。
它大概算壞掉的東西。
```

### 4.2 滅影忍者

```text
滅影忍者站在月光裡，身後分出一排影子。

「你連我的真身都看不見，怎麼打敗我？」

Ghost 沒有回答。
它開始聽地板的聲音。
```

### 4.3 U-man

```text
U-man 的胸口核心開始發光。
基地裡所有警報都變成了讚歌。

「黑暗，接受光的裁決。」

Ghost 眨了眨眼。
光太亮了，但不是第一次刺眼。
```

### 4.4 鋼筋戰士

```text
五道彩光落下，鋼筋戰士擺出完美隊形。

「團結的正義，不會輸給孤單的怨念！」

Ghost 數了一下。
一打五，果然很正義。
```

### 4.5 葫蘆爺

```text
葫蘆爺拍了拍腰間葫蘆。

「不安分的小鬼，都該收起來。」

Ghost 看著葫蘆口，突然覺得裡面可能很擠。
```

### 4.6 消炎

```text
異火在消炎掌心旋轉，像一朵被命運精心包裝的奇遇。

「弱者拿到火，只會燒死自己。」

Ghost 往前一步。
它想試試看。
```

### 4.7 失敗的面

```text
失敗的面從高樓邊緣倒掛下來。

「我感覺到了危險。你不該出現在這座城市。」

Ghost 看了看腳下。
它一直都不該出現。
```

### 4.8 吾空

```text
吾空落地時，整個競技場都在歡呼。

「別擔心，我會手下留情。」

Ghost 沉默了一秒。
通常說這句話的人，下手都不輕。
```

### 4.9 Creator

```text
Creator 坐在白色王座上，手裡拿著一支像筆又像橡皮擦的工具。

「你不是角色。你是錯誤資料。」

Ghost 身上的怨念開始重疊。
錯誤資料，也會痛。
```

## 5. Boss 戰中台詞

### 5.1 開戰台詞格式

```text
Boss：一句自信宣言。
旁白 / Ghost：一句反諷或沉默回應。
```

### 5.2 Phase 轉換台詞

| 狀態 | 台詞方向 |
|---|---|
| Phase 2 | Boss 認真起來，但仍自信。 |
| Phase 3 | Boss 啟動氣運反撲，世界開始幫忙。 |
| 被相剋破防 | Boss 慌張、否認、不相信。 |
| Boss 低血 | Boss 開始質問 Ghost 的存在。 |

### 5.3 相剋破防台詞

| Boss | 被破防台詞 |
|---|---|
| M先生 | 「你怎麼扛住了？這不符合施工規範！」 |
| 滅影忍者 | 「我的影子……被震出來了？」 |
| U-man | 「光束被穿過去了？」 |
| 鋼筋戰士 | 「合體裝甲正在解體！」 |
| 葫蘆爺 | 「別敲！葫蘆不是這樣用的！」 |
| 消炎 | 「我的火，被你吞了？」 |
| 失敗的面 | 「蛛線燒斷了？預警沒說這個！」 |
| 吾空 | 「你把我拉回地面了？」 |
| Creator | 「這不是我寫的反制。」 |

## 8. 死亡文案

### 8.1 死亡句總方向

死亡要讓玩家笑一下，但也知道自己錯在哪。

### 8.2 通用死亡句

```text
「你又成了英雄故事裡的一秒鐘。」
「世界再次證明：主角比較耐打。」
「別難過，你至少讓他放了大招。」
「復仇失敗，但怨念增加。」
「這次不是沒有機會，是你貪了第三刀。」
「你被正義擊敗。正義目前拒絕受訪。」
```

### 8.3 死因對應文案

| 死因 | 文案 |
|---|---|
| 被跳砸 | 「你站在了英雄落地的地方。這通常不是好位置。」 |
| 被分身殺 | 「真假不重要，痛是真的。」 |
| 被光束殺 | 「光照到了你，順便把你照沒了。」 |
| 被火燒死 | 「火焰沒有選邊站，但你站太久了。」 |
| 被蛛線拉死 | 「你被命運牽著走。字面意義。」 |
| 被爆氣連死 | 「他說會手下留情，可能只是忘了。」 |
| 被 Eraser 殺 | 「你被刪除了。不是死亡，是版本管理。」 |

## 9. 圖鑑文案

### 9.1 Boss 圖鑑格式

```text
名稱
英雄定位
被世界偏愛的方式
主要招式
Ghost 奪取能力
相剋提示
吐槽記錄
```

### 9.2 Boss 圖鑑範例：M先生

```text
M先生
紅帽維修工英雄。

傳說他能修好所有壞掉的城市、道路與命運。問題是，他判斷「壞掉」的方式很簡單：站在他對面，就是壞掉。

主要招式：跳砸、水管橫掃、地底噴管。
奪取能力：管線衝擊。
相剋提示：高速分身與隱身敵人，通常不喜歡地板突然抗議。
```

### 9.3 小怪圖鑑範例

```text
水管工僕
M先生的熱心支援者。

他們相信每一次揮管都是城市維修的一部分。被揮到的人通常沒有收到施工通知。
```

## 10. 事件文案

### 10.1 事件格式

```text
短場景描述
選項 A：安全但收益低
選項 B：收益高但有代價
選項 C：怪選項 / 黑色幽默
```

### 10.2 範例：英雄補給箱

```text
你發現一個英雄補給箱，上面寫著：只有正義陣營可以使用。

選項 A：打開它
獲得補給，但氣運壓力上升。

選項 B：砸碎它
獲得怨幣，下一房小怪變多。

選項 C：假裝沒看到
什麼都沒有發生。這很稀有。
```

### 10.3 範例：破碎神像

```text
一座英雄神像倒在路邊，臉上還保持著勝利微笑。

選項 A：扶起神像
氣運壓力下降，但失去少量時間與獎勵。

選項 B：敲下一塊
獲得氣運碎片，下一位 Boss 開場多一層護盾。

選項 C：在旁邊坐一下
回復少量 HP。神像看起來很失望。
```

## 11. 結局方向

### 11.1 結局 A：復仇完成

Ghost 擊敗 Creator，搶走 Eraser。

結局語氣：爽，但帶空虛。

```text
世界安靜了。
英雄沒有站起來，觀眾沒有鼓掌，劇本沒有翻到下一頁。

Ghost 第一次發現，沒有誰安排它接下來要做什麼。
```

### 11.2 結局 B：刪除規則

Ghost 不刪除英雄，而是刪除「只有英雄值得被記住」的規則。

結局語氣：最適合正史結局。

```text
英雄還是會勝利。
但這一次，倒下的人也留下了名字。

Ghost 沒有成為新的英雄。
它只是讓世界終於記得，輸掉的人也曾經存在。
```

### 11.3 結局 C：成為新 Creator

Ghost 接管劇本，開始安排新的英雄與反派。

結局語氣：黑色幽默，偏壞結局。

```text
Ghost 坐上白色王座。
它低頭看見下一個失敗者正在角落裡發抖。

原來坐在這個位置上，真的很容易覺得自己有道理。
```

## 12. 禁用文案方向

避免：

- 直接提到或模仿既有 IP 名稱。
- 使用真實人物名字做 Boss 對話。
- 過度髒話。
- 寫實血腥虐殺。
- 太長的戰鬥中台詞。
- 純網路梗堆疊，導致幾年後過時。
- 把 Ghost 寫成單純邪惡爽殺。

Ghost 是怨念，不是無腦反派。

## 14. 驗收清單

文案完成後檢查：

- 是否符合黑色幽默？
- 是否能強化「英雄偏心 / 敗者怨念」主題？
- 是否沒有直接使用既有 IP 名稱與招式？
- Boss 是否相信自己是正義？
- Ghost 是否沒有變成普通熱血主角？
- 戰鬥中台詞是否夠短？
- 死亡句是否能提示玩家錯誤？
- 道具文案是否有功能與吐槽？
- 結局是否有反轉與代價？
- 是否能直接交給 UI / 程式做資料表？
