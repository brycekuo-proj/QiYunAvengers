# 16｜關卡機制與陷阱設計 V1

專案：《氣運復仇者》 / QiYun Avengers

用途：固定 10 張地圖的環境機制、陷阱、互動物件、危險提示、相剋技能互動與 MVP 實作優先順序。

> 本文件接續：
>
> - `05_LEVEL_AND_MAP_DESIGN.md`
> - `11_CORE_GAMEPLAY_COMBAT_DESIGN.md`
> - `12_SKILL_BUILD_SYSTEM_DESIGN.md`
> - `15_ENEMY_STAGE_BALANCE_DESIGN.md`
>
> 關卡機制不是背景裝飾，而是讓玩家更清楚理解：**每個英雄世界都有自己的規則，而 Ghost 要把規則拆掉。**

## 0. 關卡機制總原則

### 0.1 設計目標

| 目標 | 說明 |
|---|---|
| 可讀 | 陷阱發動前一定要有提示。 |
| 可學 | 第一次出現要安全教學，之後再組合壓力。 |
| 可反制 | 至少部分陷阱可被技能、走位或互動破解。 |
| 有主題 | 每張地圖的陷阱要像那位 Boss 的世界。 |
| 不喧賓奪主 | 陷阱強化戰鬥，不取代戰鬥。 |
| 手機友善 | 小螢幕也能看懂安全區與危險區。 |

### 0.2 陷阱錯誤方向

避免：

- 無提示直接扣血。
- 顏色和背景太接近。
- 危險區覆蓋整個可行走空間。
- 陷阱與 Boss 大招同時全螢幕爆發。
- 需要像素級操作才能閃過。
- 因視角或 UI 遮擋導致玩家看不到。

## 1. 陷阱基本規格

### 1.1 陷阱生命週期

```text
Idle → Warning → Active → Recovery → Cooldown → Idle
```

| 狀態 | 功能 |
|---|---|
| Idle | 陷阱未啟動，可作為背景或地形。 |
| Warning | 顯示危險提示，給玩家反應。 |
| Active | 實際造成傷害、控場或阻擋。 |
| Recovery | 特效淡出，避免馬上再次傷害。 |
| Cooldown | 暫時不發動，給玩家安全窗口。 |

### 1.2 Warning 規格

| 陷阱強度 | Warning 時間 |
|---|---:|
| 小傷害 | 0.35～0.6 秒 |
| 中傷害 | 0.6～1.0 秒 |
| 高傷害 | 1.0～1.5 秒 |
| Boss 級陷阱 | 1.2～2.0 秒 |

### 1.3 傷害原則

以 Ghost 初始 HP = 100 為基準：

| 類型 | 傷害 |
|---|---:|
| 小陷阱 | 5～8 |
| 中陷阱 | 10～15 |
| 大陷阱 | 18～25 |
| Boss 場地大招 | 25～35，但必須非常清楚 |

陷阱最好不要單獨殺死滿血玩家，除非是終局高難度且有完整預告。

## 2. 陷阱功能分類

| 類型 | 效果 | 例子 |
|---|---|---|
| 傷害陷阱 | 直接扣血 | 噴管、火場、雷擊。 |
| 控場陷阱 | 緩速、束縛、推拉 | 蛛網、磁鐵、泥沼。 |
| 阻擋陷阱 | 暫時封路 | 管線牆、光盾門、白頁牆。 |
| 資源陷阱 | 吃怨念、封技能 | Eraser 碎光、氣運抽取。 |
| 互動陷阱 | 可打爆、可開關 | 閥門、開關、藥爐。 |
| 風險獎勵 | 危險區內有獎勵 | 詛咒寶箱、怨幣堆。 |

## 3. 相剋技能與陷阱互動

| 技能 | 可互動陷阱 | 效果 |
|---|---|---|
| 管線衝擊 | 隱藏地雷、地面裂縫、分身陷阱 | 震出或提前觸發。 |
| 影遁衝刺 | 雷射、直線噴管、封鎖線 | 短暫穿越。 |
| 核心光束 | 護盾門、裝甲機關、能量核心 | 穿透或破壞。 |
| 破甲合擊 | 裝甲閥門、重型機械、葫蘆封印 | 多段打斷。 |
| 吞運葫蘆 | 火球、能量彈、噴射物 | 吸收並反吐。 |
| 怨火爆燃 | 蛛網、藤蔓、回血陣 | 燒掉並禁療。 |
| 蛛線牽引 | 移動平台、空中開關、飛行敵人 | 拉動或位移。 |
| 鬥氣爆發 | 推牆、連續近戰陷阱、壓制場 | 霸體通過。 |

## 4. 地圖 0：怨念甦醒地

### 4.1 機制定位

教學地圖，機制要簡單、慢、清楚。

### 4.2 陷阱列表

| 機制 | 說明 | 教學目的 |
|---|---|---|
| 裂運地面 | 地面出現裂紋後冒出黑紫煙 | 教 Warning → Active。 |
| 怨念風 | 推動 Ghost 一小段距離 | 教位置控制。 |
| 破碎記憶球 | 打破後掉怨念糖 | 教互動物件。 |
| 低階氣運光 | 白金光圈落下，短延遲傷害 | 預告正義方氣運。 |

### 4.3 MVP 實作

先做：

```text
裂運地面 + 破碎記憶球
```

## 5. 地圖 1：紅帽管線城

### 5.1 機制定位

管線、噴氣、跳台、施工封路。

### 5.2 陷阱列表

| 機制 | 說明 | 反制 |
|---|---|---|
| 地底噴管 | 地面先冒小蒸氣，再噴出直線氣柱 | 走位 / 影遁衝刺。 |
| 施工管線牆 | 短暫升起管線阻擋路線 | 管線衝擊可打開。 |
| 彈跳井蓋 | 踩到後彈起或擊退 | 可利用躲招。 |
| 紅帽警示牌 | 發光後召喚水管工僕 | 優先打掉。 |
| 漏水滑地 | 地面濕滑，移動慣性增加 | 慢走或 Dash 脫離。 |

### 5.3 Boss 房互動

M先生跳砸可震開管線，形成臨時噴氣陷阱。Ghost 若誘導 Boss 跳到指定位置，可讓噴管反過來打中 Boss。

## 6. 地圖 2：影村訓練場

### 6.1 機制定位

隱身、假地板、分身干擾。

### 6.2 陷阱列表

| 機制 | 說明 | 反制 |
|---|---|---|
| 影紙地雷 | 看似普通紙片，靠近後爆成影刃 | 管線衝擊震出。 |
| 假身木樁 | 被打後變成短暫分身 | 範圍震波清除。 |
| 黑幕區 | 進入後視野縮小 | 站在燈籠旁恢復。 |
| 苦無牆 | 牆面延遲射出苦無 | 看孔洞提示。 |
| 影步訓練線 | 地面出現斜線，短延遲後影忍突進 | Dash 橫向躲。 |

### 6.3 Boss 房互動

滅影忍者分身會藏在黑幕區。玩家使用管線衝擊可震出真身，場地燈籠也能短暫照出分身真假。

## 7. 地圖 3：藍核防衛基地

### 7.1 機制定位

雷射、護盾門、能源倒數。

### 7.2 陷阱列表

| 機制 | 說明 | 反制 |
|---|---|---|
| 藍核雷射線 | Warning 後發射直線雷射 | 影遁衝刺穿越。 |
| 護盾門 | 只擋正面攻擊 | 核心光束穿透。 |
| 能源倒數柱 | 倒數結束後全房小脈衝 | 打斷 / 破壞。 |
| 防衛掃描光 | 掃到 Ghost 後召喚守衛球 | 走位避開。 |
| 核心過載區 | 地面藍光閃爍後爆炸 | 看圈離開。 |

### 7.3 Boss 房互動

U-man 核心光束會充能場地柱。玩家可用影遁穿過光束並誘導光束打壞自己的能源柱。

## 8. 地圖 4：鋼筋戰隊工廠

### 8.1 機制定位

機械裝甲、磁力、輸送帶、合體零件。

### 8.2 陷阱列表

| 機制 | 說明 | 反制 |
|---|---|---|
| 輸送帶 | 改變 Ghost 移動方向 | Dash 修正。 |
| 磁鐵塔 | 週期性吸引或推開 Ghost | 打掉 / 核心光束破壞。 |
| 裝甲閘門 | 重型門阻擋路線 | 破甲合擊打開。 |
| 合體零件雨 | 上方掉落機械零件 | 地面影子提示。 |
| 維修平台 | 敵人站上去回血裝甲 | 怨火或破甲打斷。 |

### 8.3 Boss 房互動

鋼筋戰士召喚零件合體時，場上裝甲閘門會發亮。玩家用核心光束破壞閘門可延緩合體。

## 9. 地圖 5：七色葫蘆山

### 9.2 陷阱列表

| 機制 | 說明 | 反制 |
|---|---|---|
| 吸風葫蘆口 | 扇形吸引 Ghost | 破甲合擊打斷。 |

## 10. 地圖 6：異火煉藥宗

### 10.1 機制定位

火場、藥爐、丹藥爆炸、回血陣。

### 10.2 陷阱列表

| 機制 | 說明 | 反制 |
|---|---|---|
| 丹爐噴火 | 固定方向噴火 | 吞運葫蘆吸收火焰彈。 |
| 爆丹地雷 | 丹藥落地後倒數爆炸 | 打遠 / 躲開。 |

### 12.1 機制定位

空中平台、氣流、蓄氣圈、重力變化。

### 12.2 陷阱列表

| 機制 | 說明 | 反制 |
|---|---|---|

## 13. 地圖 9：命運劇場

### 13.1 機制定位

規則被改寫、白頁、草稿、Eraser、前面機制混合。

### 13.2 陷阱列表

| 機制 | 說明 | 反制 |
|---|---|---|
| 白頁擦除區 | 白色區域擴張，清掉玩家場地效果 | 離開或打斷修正游標。 |
| 草稿分身門 | 召喚弱化版 Boss 招式 | 對應相剋技能。 |
| 修正游標 | 追蹤 Ghost，短暫封鎖技能 | 打掉 / 躲進陰影區。 |
| 劇本翻頁 | 場地安全區與危險區交換 | 看翻頁預告。 |
| 刪除框 | 方形框鎖定，延遲造成高傷害 | Dash 離開。 |

### 13.3 Creator 房互動

Creator 的 Eraser 會擦掉玩家持續效果，但也可能擦掉自己召喚的草稿陷阱。玩家可以誘導 Eraser 清掉場上的敵方機制。

## 15. 陷阱視覺規格

### 15.1 Warning 顏色

| 危險類型 | 顏色方向 |
|---|---|
| 敵方正義能量 | 金白、藍白，但不可刺眼。 |
| 管線危險 | 橘黃警示、蒸氣白。 |
| 忍者影陷阱 | 深紫、黑影邊緣。 |
| 火焰危險 | 橘紅外圈、紫黑中心。 |
| 蛛網危險 | 淡白線 + 紫色節點。 |
| Creator 刪除 | 白色擦除、黑色邊框、像被橡皮擦過。 |

### 15.2 手機尺寸要求

- Warning 圈至少比角色寬 1.5 倍。
- 重要陷阱不可被 UI 按鈕遮擋。
- 地面效果邊界要有外圈，不只靠顏色填滿。
- 安全區與危險區對比要足夠。

## 17. MVP 實作優先級

第一版只做 5 種機制：

1. 裂運地面。
2. 地底噴管。
3. 施工管線牆。
4. 影紙地雷。
5. 假身木樁。

理由：

- 對應教學、M先生、滅影忍者。
- 可驗證 Warning / Active / Recovery。
- 可驗證管線衝擊與影系陷阱互動。
- 不需要一次做複雜地形系統。

---

## 18. 驗收清單

每個陷阱做完後檢查：

- 是否有清楚 Warning？
- Warning 是否足夠長？
- 玩家是否有可行躲避路線？
- 是否有至少一種技能或互動反制？
- 傷害是否不會無理秒殺？
- 顏色是否和背景分離？
- 是否符合該地圖主題？
- 是否不會和 Boss 大招同時造成視覺混亂？
- 是否能被資料化調整？
- 是否在手機畫面上仍清楚？
