# 03｜美術設計

## 美術目標

《氣運復仇者》的美術要做到兩件看似矛盾的事：

1. **角色第一眼可愛、簡潔、像玩具般好讀。**
2. **世界觀仍然帶有怨念、反英雄與黑色幽默。**

因此整體方向不是寫實黑暗，也不是純兒童卡通，而是：

> **原創方塊感角色（2.5～3.5 頭身的輕度 Q 化，不是 super-deformed）+ 高完成度 2.5D 動畫遊戲渲染 + 乾淨側視戰鬥輪廓 + 可愛中帶陰森的復仇氣氛。**

---

## 最重要的美術禁則

角色雖然採「積木／玩具感」比例，但必須保持完全原創的造型語言。

### 禁止出現

- C 字形夾握手。
- 明顯可插接的圓柱凸點。
- 可看出拼裝結構的玩具關節。
- 可與特定知名拼裝玩具相容的零件結構。
- 特定品牌式小人頭身比例、手型、腿型或臉部配置。
- 在宣傳或 prompt 中直接使用既有拼裝玩具品牌名稱作為風格描述。

### 必須保留

- 圓潤。
- 簡化。
- 方塊感／模組感。
- 2.5～3.5 頭身的輕度比例壓縮；頭可以略大，但禁止 bobblehead／super-deformed／大頭小身體吉祥物化。
- **饅頭手／mitten hands**。
- 關節以動畫造型語言呈現，而不是「玩具零件」語言。

---

## 整體造型語言

### 頭身比例

建議約 **2.5～3.5 頭身**。

目的：

- Boss 仍能做出明顯姿勢。
- 手腳不會小到看不清攻擊前搖。
- 角色可以同時具有可愛感與戰鬥辨識度。

### 身體

- 軀幹與四肢要有明確的方塊／長方體量體，邊角柔和倒角，不做圓球黏土人。
- 四肢短而有厚度，但要保留肘、膝與前後肢的方向辨識，適合橫向捲軸動作。
- 手使用圓形／饅頭型輪廓，與方塊肢體形成對比。
- 腳掌簡化，不做寫實鞋底結構。
- 不畫外露機械關節。

### 臉部

臉部資訊要少。

每名角色只保留最必要的辨識元素：

- 眼睛形狀。
- 眉／面罩／符號等一項核心特徵。
- 不依賴大量細節與材質才能認出角色。

---

## Ghost 美術規格

Ghost 是整個遊戲最重要的視覺識別。

### 固定元素

- 黑紫色主調。
- 斗篷／披風輪廓。
- 發光點狀眼睛。
- 圓潤饅頭手。
- 身體結構比正義英雄更柔軟、更像一團怨念聚合物。

### 氣質

關鍵詞：

`cute / eerie / resentful / quiet / compact / readable`

不是：

`gore / horror monster / realistic ghost / skeleton`

Ghost 的可怕不來自血腥，而來自「看起來很安靜，卻一直把英雄能力搶走」。

### 輪廓

Ghost 的頭部、斗篷與手要形成一眼可辨的三段輪廓：

- 上：小而集中的發光眼睛。
- 中：斗篷主體。
- 外：兩隻圓潤手臂／手掌。

即使全黑剪影，也要和任何英雄區分開。

### 動畫方向

Idle：

- 輕微上下漂浮。
- 斗篷有 1～2 個節點的柔和擺動。
- 不需要複雜骨骼。

移動：

- 可稍微前傾。
- 手臂與斗篷延遲跟隨。

奪取能力：

- 英雄能力的代表色或符號短暫被吸入 Ghost。
- Ghost 本體不要永久變成對方造型，避免失去角色識別。

---

## M先生 美術規格

### 角色定位

正義側英雄之一；視覺上帶有維修工／工程工作者的元素。

### 固定元素

- 紅色帽子作為最主要辨識點。
- 原創工作服輪廓。
- 2.5～3.5 頭身的原創方塊感比例；頭僅略大，禁止 super-deformed／bobblehead 化。
- 饅頭手。
- 不做 C 型夾手。
- 不做任何可辨識為既有知名遊戲人物的鬍子、臉型、服裝配置或符號組合。

### 色塊原則

角色最多以 3～4 個主色塊構成。

目的不是做複雜服裝，而是讓玩家在高速戰鬥中能立即讀到：

`紅帽 → M先生 → 工具型攻擊即將來了`

### 戰鬥動畫方向

- 工具攻擊要有大幅度前搖。
- 手臂動作誇張、清楚。
- 衝擊型招式可以搭配方形／圓角幾何特效。
- 不使用過多碎屑，避免戰鬥畫面變髒。

---

## U-man 美術規格

### 固定造型

這些元素視為角色識別，不應任意改動：

- 白色身體主體。
- 粗且左右對稱的紅色紋樣。
- 白色橢圓眼。
- 藍色胸口寶石。
- 純紅色大腿。

### 角色氣質

U-man 比 M先生更像「世界認可的高階正義英雄」。

姿態應更：

- 挺拔。
- 對稱。
- 乾淨。
- 有儀式感。

這和 Ghost 的不規則柔軟輪廓形成對比。

### 戰鬥特效

建議使用：

- 幾何能量線。
- 清楚的直線光束。
- 藍色胸口寶石作為蓄力提示。
- 紅白身體保持乾淨，不讓特效長時間遮住角色。

蓄力時胸口寶石可做亮度／尺寸變化，讓玩家不用看 UI 就知道危險即將發生。

---

## 英雄共通美術規則

每位英雄都要有：

### 1. 一個 1 秒可辨識的主色

不能全部英雄都靠細節區分。

### 2. 一個招牌輪廓

例如：

- 帽子。
- 肩甲。
- 頭部形狀。
- 背部裝置。
- 武器。

但每位只需要 1～2 個大特徵。

### 3. 一個招牌能力特效語言

能力特效的形狀比粒子數量重要。

例：

- M先生：圓角衝擊／工具符號。
- U-man：直線幾何能量／胸口核心。

### 4. 可被 Ghost「偷走」的視覺符號

每個英雄能力都要能拆出一個簡單視覺符號，供 Ghost 使用能力時顯示。

這樣 Ghost 不需換裝也能讓玩家知道目前使用哪個英雄能力。

---

## 場景美術方向

場景不應搶角色。

### 原則

- 角色比背景對比更高。
- 可互動物件輪廓清楚。
- 危險物使用一致的視覺語言。
- 背景細節控制在角色以外的第二層級。

### 世界觀對比

英雄區域可以刻意做得：

- 乾淨。
- 明亮。
- 有「被世界照顧」的秩序感。

Ghost 進入後，局部可出現：

- 黑紫色殘影。
- 怨念裂紋。
- 被能力污染的幾何痕跡。

但不要把整張畫面永久染黑，否則角色與攻擊資訊會失去可讀性。

---

## UI 美術方向

UI 以最少資訊為原則。

### 戰鬥 HUD 優先資訊

- Ghost HP。
- 當前英雄能力。
- 能力冷卻／資源。
- Boss HP。

不優先加入：

- 大量屬性數字。
- 多層 Buff icon。
- 複雜裝備欄。

### 能力圖示

每個英雄能力圖示應由：

`英雄代表符號 + 單一能力形狀`

組成。

圖示在 48～64 px 大小仍應能辨認。

---

## 色彩策略

### Ghost

- 黑。
- 深紫。
- 少量高亮眼睛色。

### M先生

- 紅色作為第一辨識色。
- 工作服使用中性色或與紅色分離的第二色。

### U-man

- 白色為主。
- 紅色對稱紋樣。
- 藍色胸口寶石作唯一高亮能量核心。

### 場景

背景飽和度通常低於角色。

Boss 招式出現時，特效顏色可以短暫高於背景，但不要高於角色識別色太多。

---

## 2D 製作方式建議

第一階段優先選擇低成本、可快速疊代的方式：

- 角色以分件 2D PNG / Sprite 為主。
- 關鍵動作用少量手繪 key pose 或骨骼補間。
- 特效用簡單幾何 sprite、shader 或程序動畫。
- 避免第一版就製作高幀數逐格動畫。

### 角色最小分件

Ghost：

- Body/Cloak
- Left Hand
- Right Hand
- Eyes
- Optional shadow / aura

英雄：

- Head
- Torso
- Left Arm
- Right Arm
- Left Leg
- Right Leg
- Signature prop / weapon（若有）

目標是讓同一套角色素材能支援：

- Idle
- Run / Move
- Attack
- Hit
- Defeat
- Boss Intro

---

## Image Generation Prompt 基線

未來用 AI 生成角色概念圖時，prompt 應描述原創造型特徵，而不是引用既有品牌。

### 共通 prompt 關鍵詞

`original stylized block-figure action-game character, compact 2.5–3.5-head-tall proportions, NOT super-deformed, head only slightly enlarged, solid cuboid torso and limbs with softly beveled corners, rounded mitten hands, no visible toy joints, no studs, no gripping C-shaped hands, premium 2.5D anime-game illustration, crisp graphic linework, painterly cel shading, controlled material highlights and rim light, layered costume/armor/cloth construction fully preserved, signature props and markings fully preserved, readable side-scroller silhouette, clean color blocking`

### Ghost 補充

`black-purple cloak, tiny glowing dot eyes, cute but eerie ghost, floating posture, rounded mitten hands`

### U-man 補充

`white body, bold symmetrical red markings, white oval eyes, blue chest gemstone, solid red thighs, heroic upright pose`

---

## 美術驗收清單

每張正式角色圖進遊戲前都檢查：

- [ ] 剪影縮小後仍能辨認角色。
- [ ] 手不是 C 型夾手。
- [ ] 沒有玩具插接凸點。
- [ ] 沒有可見拼裝關節。
- [ ] 沒有與知名拼裝小人相同的比例與零件語言。
- [ ] 主色不超過必要數量。
- [ ] 招牌能力有清楚視覺符號。
- [ ] 攻擊前搖能從角色姿勢讀懂。
- [ ] 特效不遮住角色核心輪廓。
- [ ] Ghost 使用偷來的能力時仍然看起來是 Ghost。

---

## Vertical Slice 美術交付物

第一階段只需要完成：

### Ghost

- 1 張面向畫面右側的 80–90° 真正側身概念基準；遊戲內向左由 Godot 水平鏡像。
- Idle。
- Move。
- Attack。
- Dash。
- Hit。
- Ability Cast。

### M先生

- 1 張面向畫面右側的 80–90° 真正側身基準立繪；向左由 Godot 水平鏡像。
- Idle。
- 2～3 個 Boss 招式。
- Defeat。
- 可奪能力特效。

### U-man

- 1 張面向畫面右側的 80–90° 真正側身基準立繪；向左由 Godot 水平鏡像。
- Idle。
- 2～3 個 Boss 招式。
- Defeat。
- 可奪能力特效。

### 場景

- 1 套主場景 Tiles / 模組。
- 2 個 Boss Arena 變體。
- 基礎危險物件。

### UI

- HP。
- Boss HP。
- 能力 Slot。
- 2 個能力 Icon。

完成這些就足夠做第一次完整美術與玩法驗證，不需要先建立大量英雄素材庫。
