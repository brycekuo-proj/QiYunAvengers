# 14｜Boss 戰鬥設計 V1

專案：《氣運復仇者》 / QiYun Avengers

用途：固定 8 位正義側 Boss 與 Final Boss Creator 的實戰節奏、Phase、招式、破綻、相剋反應、掉落能力與 MVP 實作優先級。

> 本文件接續：
>
> - `04_BOSS_AND_MINIONS.md`
> - `11_CORE_GAMEPLAY_COMBAT_DESIGN.md`
> - `12_SKILL_BUILD_SYSTEM_DESIGN.md`
> - `13_ITEM_RELIC_EFFECT_DESIGN.md`

> Boss 戰的核心不是單純打血條，而是讓玩家完成：**看懂英雄套路 → 活下來 → 找破綻 → 搶走招式 → 用它報復下一位英雄。**

## 0. Boss 戰總原則

### 0.1 每位 Boss 必須有的東西

| 項目 | 說明 |
|---|---|
| 清楚主題 | 玩家一看就知道這位 Boss 的世界與戰鬥語言。 |
| 招牌能力 | 打敗後會變成 Ghost 的可用技能。 |
| 3～5 個核心招式 | 不靠招式數量堆難度。 |
| 明確破綻 | 高傷招式後一定有反擊窗口。 |
| 相剋反應 | 被對應 Ghost 技能命中時有特殊破防。 |
| 氣運反撲 | 殘血時出現英雄式逆轉，但不能無解。 |
| 黑色幽默台詞 | 正義方看似熱血，從 Ghost 視角很諷刺。 |

### 0.2 Boss 戰錯誤方向

不要做成：

- 全螢幕無預警秒殺。
- Boss 一直霸體，玩家沒有反擊窗口。
- 每位 Boss 只是不同皮膚的衝撞怪。
- 相剋只加傷害，沒有肉眼可見的破防反應。
- Boss 直接使用既有 IP 標誌、招式名稱或辨識性姿勢。

## 1. Boss Phase 結構

### 1.1 標準三段式

| Phase | 血量 | 目的 | 招式設計 |
|---|---:|---|---|
| Phase 1 | 100%～65% | 教學 | 展示 Boss 基本能力，前搖明顯。 |
| Phase 2 | 65%～30% | 組合 | 招式開始連接，加入場地或小怪干擾。 |
| Phase 3 | 30%～0% | 氣運反撲 | Boss 嘗試主角式逆轉，節奏變快但破綻仍存在。 |

### 1.2 MVP 簡化二段式

第一版可先做：

```text
Phase 1：基本招式
Phase 2：殘血反撲 + 招牌大招
```

只要相剋破防與能力奪取成立，Boss 數量比 Phase 複雜度更重要。

## 2. Boss 共通招式模板

| 招式類型 | 功能 | 設計要求 |
|---|---|---|
| 近身懲罰 | 防止玩家無腦貼臉 | 起手快，但傷害中等。 |
| 遠距壓迫 | 防止玩家一直逃跑 | 彈道清楚，可走位閃。 |
| 範圍控制 | 逼玩家換位置 | 地面提示必須清楚。 |
| 招牌技能 | 掉落能力原型 | 視覺最鮮明。 |
| 破綻技能 | 給玩家輸出窗口 | 後搖較長。 |
| 氣運反撲 | 殘血壓力 | 有預告，不可偷襲。 |

## 3. 相剋破防規則

### 3.1 破防要肉眼可見

對應技能命中 Boss 弱點時，必須出現：

- Boss 動作被打斷。
- 護盾碎裂或姿勢失衡。
- 出現黑紫裂光。
- 血條下方出現 `BROKEN LUCK` 或中文版「氣運破裂」提示。
- Boss 短暫跪地 / 暈眩 / 掉落怨念。

### 3.2 破防時長

| Boss 類型 | 建議破防時長 |
|---|---:|
| 早期 Boss | 2.0～3.0 秒 |
| 中期 Boss | 1.5～2.5 秒 |
| 後期 Boss | 1.0～2.0 秒 |
| Creator | 0.6～1.5 秒，依階段變化 |

### 3.3 破防冷卻

為避免玩家無限控 Boss：

```text
同一 Boss 破防後，進入 8～15 秒破防免疫。
```

但免疫期間對應技能仍可造成普通傷害，不應完全無效。

## 4. Boss 1：M先生

### 4.1 戰鬥定位

紅帽維修工式正義英雄，擅長跳砸、管線揮擊、地面震波。

定位：第一位主要 Boss，教玩家看前搖、躲跳砸、打後搖。

掉落技能：**管線衝擊**。

相剋技能：被 **鬥氣爆發** 反制。

### 4.2 Phase 設計

| Phase | 行為 |
|---|---|
| P1 | 水管揮擊、短跳砸、直線衝撞。 |
| P2 | 加入地面裂管、二連跳砸、召喚補給小角。 |
| P3 | 氣運反撲：巨大跳砸 + 管線噴發。 |

### 4.3 招式表

| 招式 | 前搖 | 效果 | 破綻 |
|---|---:|---|---|
| 水管橫掃 | 短 | 前方扇形近戰 | 揮完後停頓。 |
| 紅帽跳砸 | 中 | 跳到玩家附近造成圓形震波 | 落地後硬直。 |
| 管線突進 | 中 | 直線衝撞，撞牆後暈一下 | 衝撞落空可反打。 |
| 地底噴管 | 長 | 地面提示後噴出水柱 / 蒸氣 | 可離開提示區。 |
| 正義施工中 | 長 | 殘血大招，連續 3 次地面噴發 | 第三次後大硬直。 |

### 4.4 相剋反應

Ghost 使用 `鬥氣爆發`：

- 可硬扛水管橫掃不被擊退。
- 在 M先生跳砸落地瞬間反擊，可造成氣運破裂。
- Boss 台詞從自信變成慌張。

### 4.5 台詞方向

```text
「別擋路，我正在修理這個世界！」
「壞掉的東西就該被敲掉。」
「等等，你怎麼還站著？」
```

## 5. Boss 2：滅影忍者

### 5.1 戰鬥定位

忍者村天才英雄，靠瞬身、分身、背刺、苦無壓迫玩家。

定位：教玩家處理隱身、分身與多方向威脅。

掉落技能：**影遁衝刺**。

相剋技能：被 **管線衝擊** 反制。

### 5.2 Phase 設計

| Phase | 行為 |
|---|---|
| P1 | 苦無投擲、短瞬身斬。 |
| P2 | 加入分身，分身會模仿一部分動作。 |
| P3 | 氣運反撲：全場影分身包圍，真身準備背刺。 |

### 5.3 招式表

| 招式 | 前搖 | 效果 | 破綻 |
|---|---:|---|---|
| 苦無三連 | 短 | 三方向投射物 | 投擲後站定。 |
| 影步斬 | 中 | 消失後從側面斬擊 | 現身瞬間可閃避。 |
| 紙影分身 | 中 | 召喚 2～4 個假身 | 假身 HP 低。 |
| 背後一刀 | 長 | 標記玩家背後後突刺 | Dash 可穿過。 |
| 影村畢業式 | 長 | 殘血多分身連斬 | 真身有較深色影子。 |

### 5.4 相剋反應

Ghost 使用 `管線衝擊`：

- 地面震波會震出隱身真身。
- 分身被震波命中會直接破碎。
- 真身現形後進入 2 秒破防。

### 5.5 台詞方向

```text
「看不見我，就是你技不如人。」
「分身也是努力的一部分。」
「你居然用施工噪音破了我的忍法？」
```

## 6. Boss 3：U-man

### 6.1 戰鬥定位

白紅光之巨人系正義英雄，胸口藍核、直線光束、護盾、倒數爆發。

定位：教玩家穿越直線危險與打核心弱點。

掉落技能：**核心光束**。

相剋技能：被 **影遁衝刺** 反制。

### 6.2 Phase 設計

| Phase | 行為 |
|---|---|
| P1 | 直線光束、核心閃光、短護盾。 |
| P2 | 光束掃射、能源球、小型防衛隊支援。 |
| P3 | 胸口倒數，若未打斷則全場爆光。 |

### 6.3 招式表

| 招式 | 前搖 | 效果 | 破綻 |
|---|---:|---|---|
| 核心直射 | 中 | 水平或斜向光束 | 光束後核心過熱。 |
| 光之護盾 | 短 | 正面減傷 | 背後與核心可打。 |
| 藍核脈衝 | 長 | 圓形擴散波 | 擴散後硬直。 |
| 能源球降落 | 中 | 多個地面預警點爆炸 | 可走位。 |
| 三秒正義 | 長 | 殘血倒數爆發 | 倒數期間核心可破。 |

### 6.4 相剋反應

Ghost 使用 `影遁衝刺`：

- 可穿過核心直射，不受傷。
- 穿過光束後 1 秒內攻擊胸口核心，造成破防。
- 破防時 U-man 的胸口藍核變成黑紫裂光。

### 6.5 台詞方向

```text
「黑暗，接受光的裁決！」
「我的核心，是守護世界的證明。」
「你穿過了光？不可能。」
```

## 7. Boss 4：鋼筋戰士

### 7.1 戰鬥定位

彩色戰隊合體英雄，擅長隊友援護、裝甲、盾衝與變身。

定位：教玩家處理護甲與多段打斷。

掉落技能：**破甲合擊**。

相剋技能：被 **核心光束** 反制。

### 7.2 Phase 設計

| Phase | 行為 |
|---|---|
| P1 | 盾衝、拳擊、短暫裝甲。 |
| P2 | 呼叫隊友影像援護，形成多方向攻擊。 |
| P3 | 合體裝甲，護盾厚但核心暴露。 |

### 7.3 招式表

| 招式 | 前搖 | 效果 | 破綻 |
|---|---:|---|---|
| 正義盾衝 | 中 | 直線突進，帶護甲 | 撞牆後硬直。 |
| 雙拳合擊 | 短 | 近戰二連 | 第二拳後可反打。 |

- 直接穿透合體護甲。

- Boss 失去護甲後短時間行動變慢。

### 7.5 台詞方向

```text
「一個人的怨念，打不過團隊的正義！」
「合體完成，勝利已經寫好了！」
「等等，誰把我們的裝甲打穿了？」
```

### 8.3 招式表

| 招式 | 前搖 | 效果 | 破綻 |

|---|---|
| P1 | 蛛線拉扯、牆跳踢擊。 |
| P2 | 建立蛛網地形，限制玩家移動。 |
| P3 | 全場預警反擊，牽引玩家到危險區。 |

### 10.3 招式表

| 招式 | 前搖 | 效果 | 破綻 |
|---|---:|---|---|
| 蛛線拉扯 | 中 | 把 Ghost 拉向指定點 | 線可被燒斷。 |
| 牆跳踢 | 短 | 從牆面斜向突進 | 落地後停頓。 |
| 預警反擊 | 中 | 玩家攻擊時反打 | 不攻擊可等待結束。 |

### 10.5 台詞方向

```text

「不對，這條線怎麼燒起來了？」
```

## 12. Final Boss：Creator

### 12.1 戰鬥定位

Creator 是創造正義使者的人，也象徵「劇本」「規則」「世界偏愛英雄的手」。

它會使用前面所有正義英雄的招式，但不是簡單複製，而是像設計者一樣「調用」「重畫」「刪除」。

終極大招：**Eraser**。

### 12.2 三段變身

| Phase | 名稱 | 外型方向 | 戰鬥主題 |
|---|---|---|---|
| P1 | 創辦者 | 極簡黑白、發布會、設計師、產品神話感 | 改規則、召喚低階英雄招式。 |
| P2 | 完美英雄 | 披風、光、救世主輪廓、胸前無標誌 | 使用多位英雄能力混合版。 |
| P3 | 神話創造者 | 雷霆、白袍、王座、巨大手掌、畫面被擦除 | Eraser、刪除場地、暫封技能。 |

注意：不可使用真實人物肖像、既有超級英雄標誌、既有神祇符號或可辨識 IP 造型。

### 12.3 Creator 招式表

| 招式 | Phase | 效果 | 對應反制 |
|---|---|---|---|
| Draft Clone | P1 | 召喚草稿分身 | 管線衝擊震碎。 |
| Patch Beam | P1 / P2 | 直線修正光束 | 影遁衝刺穿越。 |

### 12.4 Eraser 規則

Eraser 不應永久刪除玩家能力，只能暫時壓制。

可能效果：

- 清除 Ghost 投射物。
- 擦掉怨火、蛛網、地裂等場地效果。
- 暫時封鎖一個主動技能 5～8 秒。
- 把場地安全區擦成危險區。
- 讓 Boss 血條短暫出現白色「修正」護盾。

反制條件：

```text
Eraser 前搖期間，玩家用正確相剋技能命中 Creator 的當前調用招式。
```

## 14. Boss 房配置

### 14.1 基本規格

| 項目 | 建議 |
|---|---|
| 房間大小 | 比一般戰鬥房大 1.5～2 倍。 |
| 安全邊界 | 邊界不可完全被特效遮住。 |
| 地形 | 每位 Boss 最多 1～2 種主要地形機制。 |
| 小怪支援 | Phase 2 起少量出現，不可蓋過 Boss。 |
| 補給 | Boss 前安全區給少量補給或商店。 |

### 14.2 手機畫面限制

- 同時存在的大型危險提示不超過 3 個。
- Boss 本體永遠要清楚可見。
- 彈幕不可與地面陷阱同色。
- 玩家受擊、破防、相剋提示必須比背景更醒目。

## 17. Boss 戰驗收清單

每位 Boss 做完後檢查：

- 30 秒內能否看懂 Boss 主題？
- 招牌招式是否和掉落技能一致？
- 大招是否有清楚前搖？
- 普通玩家是否有可行閃避路線？
- 是否存在至少 1 個明確反擊窗口？
- 相剋技能是否有特殊破防演出？
- Phase 變化是否可理解？
- 小怪支援是否沒有搶走 Boss 主角地位？
- 死亡後玩家是否知道下次該改什麼？
- 打贏後玩家是否期待使用新能力？
