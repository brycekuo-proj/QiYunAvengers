# 11｜核心玩法與戰鬥設計 V1

專案：《氣運復仇者》 / QiYun Avengers

用途：固定本作的核心戰鬥循環、角色操作、敵人節奏、Boss 戰規則、能力奪取與相剋體驗，作為後續 Prototype / Vertical Slice / MVP 實作依據。

> 本文件接續 `01_GAME_OVERVIEW.md`、`02_GAMEPLAY.md`、`04_BOSS_AND_MINIONS.md`、`05_LEVEL_AND_MAP_DESIGN.md`。
>
> 核心不能偏離一句話：**Ghost 打英雄、搶能力、用搶來的能力破解下一位英雄。**

---

## 0. 戰鬥設計總目標

《氣運復仇者》的戰鬥不是單純刷怪，也不是只比數值堆疊。

玩家每一局要反覆經歷：

```text
弱勢進場 → 讀懂英雄勢力 → 打穿小怪防線 → 看破 Boss 招式 → 擊敗 Boss → 奪取能力 → 用新能力破解下一關
```

戰鬥的爽感來自三層：

1. **操作爽感**：Ghost 小、快、靈活，靠閃避與短爆發活下來。
2. **破解爽感**：每個 Boss 有明確套路，被正確能力克制時會明顯破防。
3. **復仇爽感**：剛才欺負玩家的英雄招式，之後變成玩家手上的武器。

## 1. 核心遊戲循環

### 1.1 單局流程

```text
開始一局
  ↓
選擇初始怨念核心 / 初始小強化
  ↓
進入地圖節點
  ↓
小怪戰 / 事件 / 商店 / 精英戰
  ↓
獲得局內強化、道具、怨念、金幣
  ↓
Boss 戰
  ↓
擊敗 Boss 並奪取招牌能力
  ↓
選擇下一個地圖 / 下一位英雄
  ↓
重複直到 Final Boss 或死亡
```

### 1.2 單場戰鬥流程

```text
進場預警
  ↓
小怪生成 / Boss 出場
  ↓
玩家觀察攻擊前搖
  ↓
走位、閃避、普攻、技能反擊
  ↓
敵人進入硬直 / 破防 / 狂暴
  ↓
玩家輸出窗口
  ↓
下一輪招式循環
  ↓
勝利 / 失敗
```

### 1.3 每場戰鬥必須回答的問題

每場戰鬥都要讓玩家快速理解三件事：

| 問題 | 玩家應該看到什麼 |
|---|---|
| 這個敵人怎麼打我？ | 清楚前搖、軌跡、範圍提示。 |
| 我怎麼躲？ | 有可行走位、閃避時機、地形空間。 |
| 我怎麼反打？ | 有硬直、破防、背後、冷卻空窗或相剋技能窗口。 |

如果敵人的攻擊不可讀、不可躲、不可反制，這不是難，是壞設計。

## 2. 玩家角色：Ghost

### 2.1 Ghost 定位

Ghost 是玩家主角，代表敗者怨念集合體。

戰鬥定位：

- 小體型。
- 高機動。
- 低初始血量。
- 靠閃避、短爆發、能力組合生存。
- 不靠巨大武器或厚重裝甲。
- 每擊敗 Boss 後獲得一個新的主動能力或關鍵機制。

### 2.2 Ghost 初始能力

| 行動 | 功能 | 設計目的 |
|---|---|---|
| 移動 | 左右 / 上下或橫向移動 | 基本走位。 |
| 閃避 Dash | 短距離位移，短暫無敵 | 用來穿越危險區與 Boss 招式。 |
| 怨念爪擊 | 近距離普攻，連段 2～3 下 | 提供基礎輸出與操作節奏。 |
| 怨念彈 | 短距離小投射物，可選配 | 避免完全貼臉造成操作壓力過高。 |
| 奪運槽 | 打敵人累積能量 | 連接技能、爆發、Boss 奪取。 |
| 主動技能槽 | 裝備 Boss 掉落能力 | 本作核心 Build 空間。 |

### 2.3 Ghost 戰鬥狀態機

```text
IDLE
MOVE
DASH
BASIC_ATTACK_1
BASIC_ATTACK_2
BASIC_ATTACK_3
SKILL_CAST
CHARGE
HIT_STUN
INVINCIBLE
KNOCKBACK
DOWNED
DEAD
VICTORY
```

狀態規則：

- `DASH` 可取消 `MOVE`，但不可無限取消攻擊後搖。
- `BASIC_ATTACK` 前兩段可微移動，最後一段需要短暫站樁，換取較高傷害。
- `SKILL_CAST` 依技能類型決定是否能移動。
- `HIT_STUN` 結束後給短暫無敵，避免被連續小怪秒殺。
- `DEAD` 後直接進入死亡結算，不做長讀取。

## 3. 操作規格

### 3.1 Mobile 優先操作

本作若做手機版，按鍵不宜太多。

建議 Mobile Layout：

| 區域 | 操作 |
|---|---|
| 左下 | 虛擬搖桿 / 滑動移動 |
| 右下大鍵 | 普攻 |
| 右下小鍵 1 | 閃避 |
| 右下小鍵 2 | 主技能 A |
| 右下小鍵 3 | 主技能 B / 互動 |
| 右上 | 暫停 |

MVP 先控制在：

```text
移動 + 普攻 + 閃避 + 1 個 Boss 技能
```

等核心打擊感成立，再增加第二技能槽。

### 3.2 PC / Web Prototype 操作

| 鍵位 | 行動 |
|---|---|
| WASD / 方向鍵 | 移動 |
| J / 滑鼠左鍵 | 普攻 |
| K / Space | 閃避 |
| L / 滑鼠右鍵 | 技能 A |
| I / Shift | 技能 B / 爆發 |
| E | 互動 |
| Esc | 暫停 |

## 4. 戰鬥資源系統

### 4.1 HP

Ghost 血量不高，避免變成站樁互毆。

設計原則：

- 小怪普攻不應一擊秒殺。
- Boss 大招可以非常痛，但必須有明顯前搖。
- 連續受擊要有保護時間。
- 補血稀少，讓風險判斷重要。

### 4.2 怨念值

怨念值是 Ghost 的戰鬥能量。

來源：

- 普攻命中。
- 完美閃避。
- 擊殺小怪。
- Boss 破防。
- 特定道具或遺物效果。

用途：

- 釋放高級技能。
- 啟動短暫爆發。
- 觸發某些遺物效果。
- Boss 戰最後奪取能力時作為視覺與敘事資源。

### 4.3 氣運壓力

氣運不是一般魔力，而是世界偏愛英雄的壓力。

可做成局內隱性或顯性系統：

| 氣運狀態 | 效果 |
|---|---|
| 低 | 普通戰鬥。 |
| 中 | 小怪支援變多、補給減少。 |
| 高 | 英雄獲得額外護盾或奇蹟反擊。 |
| 爆表 | Boss 進入命運反撲，使用一次「主角光環」式逆轉招。 |

注意：氣運壓力是用來製造戲劇張力，不是用來偷偷作弊。玩家必須能看懂：現在世界開始偏袒英雄了。

## 5. 傷害類型與戰鬥標籤

為了支援能力相剋，所有攻擊可以附帶標籤。

| 標籤 | 用途 | 代表技能 |
|---|---|---|
| `impact` | 擊退、震地、破隱 | 管線衝擊 |
| `shadow` | 位移、穿越、背刺 | 影遁衝刺 |
| `core` | 直線能量、穿盾 | 核心光束 |
| `armor_break` | 破甲、多段打斷 | 破甲合擊 |
| `devour` | 吸收、反吐、封投射物 | 吞運葫蘆 |
| `flame` | 持續傷害、禁療、燒線 | 怨火爆燃 |
| `web` | 牽引、束縛、拉回空中敵人 | 蛛線牽引 |
| `ki` | 霸體、近戰爆發、抗硬直 | 鬥氣爆發 |
| `erase` | Final Boss 清除、壓制 Build | Creator / Eraser |

標籤不是給玩家背表，而是讓設計與程式都能用同一套語言描述相剋。

## 6. 普攻與打擊感

### 6.1 普攻連段

Ghost 普攻建議 3 段：

| 段數 | 動作 | 功能 |
|---|---|---|
| 1 | 快速爪擊 | 起手快，低傷害。 |
| 2 | 橫掃 | 稍大範圍，可清小怪。 |
| 3 | 怨念重擊 | 高傷害，可造成小硬直。 |

### 6.2 普攻設計原則

- 起手要快，手感不能笨重。
- 第三段可稍慢，形成選擇：貪刀或閃避。
- 命中要有小停頓 hit stop。
- 敵人受擊要有明確閃白 / 抖動 / 小擊退。
- 不要用血腥效果，使用黑紫煙、碎運片、星星暈眩。

### 6.3 打擊感基礎參數

| 項目 | 建議 |
|---|---|
| hit stop | 0.04～0.08 秒 |
| 小怪擊退 | 8～24 px 或等效距離 |
| Boss 擊退 | 多數時間免疫，只進入破防時退後 |
| 受擊無敵 | 0.6～1.0 秒 |
| 閃避無敵 | 0.15～0.3 秒 |
| 閃避冷卻 | 0.6～1.2 秒 |

## 7. 小怪戰設計

### 7.1 小怪職責

小怪不是拖時間用的血包，而是用來教玩家 Boss 關卡語言。

每張地圖的小怪要做到：

- 預告該關 Boss 的主題。
- 練習一種主要閃避方式。
- 練習一種主要反擊窗口。
- 給玩家少量資源，推動局內 Build。

### 7.2 小怪類型

| 類型 | 功能 | 玩家解法 |
|---|---|---|
| 近戰追擊 | 逼玩家移動，不可站樁 | 走位、普攻打斷、拉距離 |
| 遠程射擊 | 形成彈道壓力 | 橫移、Dash、反射或吸收 |
| 輔助干擾 | 補血、上盾、召喚、警報 | 優先擊殺 |
| 精英小怪 | 小型 Boss 機制 | 觀察前搖與技能克制 |
| 環境裝置 | 地刺、管線、雷射、蛛網 | 節奏記憶與地形利用 |

### 7.3 小怪組合規則

早期：

```text
1 種近戰 + 1 種遠程
```

中期：

```text
近戰 + 遠程 + 輔助
```

後期：

```text
精英 + 支援小怪 + 環境危險
```

同一畫面不應塞滿太多攻擊提示。手機畫面尤其要避免彈幕變成雜訊。

## 8. Boss 戰設計

### 8.1 Boss 戰三段節奏

每位 Boss 建議 3 段血量節奏，但 MVP 可先做 2 段。

| 階段 | 血量 | 行為 |
|---|---:|---|
| Phase 1 | 100%～65% | 展示核心招式，招式簡單。 |
| Phase 2 | 65%～30% | 招式組合，加入支援小怪或場地變化。 |
| Phase 3 | 30%～0% | 氣運反撲，出現大招或主角光環式逆轉。 |

### 8.2 Boss 招式構成

每位 Boss 最少需要：

| 招式 | 用途 |
|---|---|
| 快速招 | 讓玩家不能無腦貼身。 |
| 範圍招 | 逼玩家離開固定位置。 |
| 招牌招 | 對應掉落能力。 |
| 破綻招 | 給玩家反擊窗口。 |
| 氣運反撲 | 殘血時的戲劇逆轉。 |

### 8.3 Boss 公平性規則

- 大傷害招式必須有明顯前搖。
- 螢幕外不可突然打中玩家。
- Boss 不應連續使用兩次無解追蹤技。
- 召喚小怪時，Boss 本體要短暫降低壓力。
- 進入新 Phase 時允許短暫停頓，給玩家理解變化。
- 相剋技能命中時，要有明顯破防、打斷或護盾破裂回饋。

## 9. 能力奪取設計

### 9.1 奪取流程

```text
Boss HP 歸零
  ↓
Boss 進入氣運剝離動畫
  ↓
Ghost 靠近或自動吸收
  ↓
招牌能力化成黑紫怨念版本
  ↓
能力解鎖教學
  ↓
下一關可立即使用
```

### 9.2 能力黑化原則

Boss 原版能力是正義、明亮、英雄式。

Ghost 奪取後要變成：

- 黑紫色。
- 邊緣像煙或破碎氣運。
- 保留功能輪廓，但視覺語氣變成怨念版。
- 不直接複製英雄原招式特效。

例：

```text
U-man 的藍白核心光束 → Ghost 的黑紫核心光束，中心有破碎藍光殘影。
```

### 9.3 能力限制

為避免搶到能力後遊戲失控：

- 每個能力有冷卻。
- 強力能力消耗怨念值。
- 同時裝備技能槽有限。
- 相剋時特別強，非相剋時仍可用但不應萬能。
- Boss 可對非相剋能力有抗性。

## 11. 場地與地圖節奏

### 11.1 戰鬥場地尺寸

MVP 可採固定戰鬥房間或橫向場景。

建議場地類型：

| 類型 | 用途 |
|---|---|
| 小房間 | 快速小怪戰。 |
| 長走廊 | 遠程與衝刺教學。 |
| 圓形競技場 | Boss 戰。 |
| 多平台場 | 忍者、蛛網、空中敵人。 |
| 危險地形場 | 火、管線、雷射、蛛網等地形壓力。 |

### 11.2 每關節奏

一張地圖建議：

```text
入口安全區
  ↓
小怪教學戰
  ↓
混合小怪戰
  ↓
事件 / 商店 / 補給
  ↓
精英戰或危險房
  ↓
Boss 前安全區
  ↓
Boss 戰
```

## 12. 失敗與死亡

### 12.1 死亡不是懲罰，而是學習

玩家死亡後應該得到資訊：

- 被哪種招式殺死。
- 這招的可視前兆是什麼。
- 哪種能力可能克制它。
- 本局最致命的錯誤是貪刀、亂閃、沒先殺輔助，還是 Build 不合。

### 12.2 死亡結算文字風格

可使用黑色幽默短句：

```text
「世界再次證明：英雄比較有道理。」
「你差一點就復仇成功了。差一點也是輸。」
「這次不是你太弱，是他們的氣運太吵。」
```

## 13. Final Boss：Creator 戰鬥定位

Creator 是創造正義使者的人，是世界敘事權本身。

它不是普通 Boss，而是對玩家已累積能力的總考。

### 13.1 三段變身

| 階段 | 外型方向 | 戰鬥主題 |
|---|---|---|
| Phase 1：創辦者 | 極簡黑白、發布會、設計師、產品神話感 | 改寫規則、召喚低階英雄招式。 |
| Phase 2：完美英雄 | 披風、光、肌肉輪廓、救世主姿態 | 使用多位英雄能力的強化版。 |
| Phase 3：神話創造者 | 雷霆、白袍、王座、巨大手掌 | 清除、重畫、刪除玩家 Build。 |

注意：外型只能作為原創概念，不使用真實人物肖像，也不直接複製任何既有超級英雄或神祇標誌。

### 13.2 終極大招：Eraser

`Eraser` 是 Creator 的最終大招。

功能方向：

- 暫時封鎖玩家一個技能槽。
- 清除場上的怨念火、蛛線、投射物或召喚物。
- 讓玩家看到「自己的 Build 被刪掉」的壓迫感。
- 不應永久刪除玩家能力，避免造成挫敗過高。

反制方式：

- 玩家要用前面學到的相剋邏輯，依序打斷 Creator 調用的英雄能力。
- Eraser 前搖必須明顯，例如巨大橡皮擦形狀、白色刪除框、畫面邊緣被擦掉。
- 滿足條件時 Ghost 可反奪取 Eraser，形成結局爆點。

## 14. MVP 戰鬥範圍

最小可行版本不要一次做 8 個 Boss。

建議 MVP：

| 內容 | 數量 |
|---|---:|
| Ghost | 1 |
| 小怪 | 6～9 種 |
| 地圖 | 2 張 |
| Boss | 2 位 |
| 可奪取能力 | 2 個 |
| 相剋關係 | 至少 1 組 |
| 遺物 | 10～15 個 |
| 技能升級 | 每技能 3～5 個 |

推薦 MVP 路線：

```text
教學地圖：怨念甦醒地
  ↓
M先生：取得管線衝擊
  ↓
滅影忍者：驗證管線衝擊破隱與破分身
```

只要這條路線成立，就能證明本作核心。

## 16. 戰鬥驗收標準

Vertical Slice 完成後，用以下問題驗收：

- 玩家能否在 30 秒內理解移動、普攻、閃避？
- 玩家是否能看懂小怪攻擊前搖？
- 玩家是否能感覺普攻命中有回饋？
- Boss 大招是否看起來危險，但可以躲？
- 擊敗 Boss 後，新技能是否立刻好玩？
- 新技能是否真的能克制下一個 Boss 或敵人？
- 玩家死亡後是否知道下次要改什麼？
- 單局是否能在 10～20 分鐘內完成一段明確進度？

## 17. 不做清單

目前不優先做：

- 複雜連招格鬥系統。
- 大量裝備數值比較。
- 開放世界探索。
- 多人連線。
- 寫實血腥斷肢。
- 完整 3D Boss 戰。
- 過多按鍵與複雜技能輪盤。
- 需要玩家背大量文字的克制表。

所有新需求都要回到核心問題：

```text
它有沒有讓「打英雄 → 搶能力 → 相剋下一位英雄」更好玩？
```

如果沒有，就延後。
