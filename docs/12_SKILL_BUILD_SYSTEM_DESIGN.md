# 12｜技能與 Build 系統設計 V1

專案：《氣運復仇者》 / QiYun Avengers

用途：固定 Ghost 的技能槽、Boss 能力奪取、技能升級、局內三選一、Build 類型與相剋策略，避免系統膨脹成純數值堆疊。

> 技能系統的核心不是「技能越多越強」，而是：**玩家用英雄的招式組出自己的復仇方式。**

---

## 0. 技能系統總原則

《氣運復仇者》的技能設計必須符合四個條件：

1. **來源清楚**：玩家知道這招是從哪個 Boss 搶來的。
2. **用途清楚**：每招都有戰鬥功能，不只是不同顏色的傷害。
3. **相剋清楚**：遇到適合的敵人時，技能會明顯發揮破解效果。
4. **Build 清楚**：玩家能圍繞技能形成打法，而不是只選最高 DPS。

技能升級可以強化傷害，但不能只剩傷害。

## 1. 技能分類

### 1.1 依來源分類

| 類型 | 說明 | 例子 |
|---|---|---|
| 初始怨念技 | Ghost 原生能力 | 怨念爪擊、怨念彈、短距離 Dash |
| Boss 奪取技 | 擊敗英雄後取得 | 管線衝擊、影遁衝刺、核心光束 |
| 遺物觸發技 | 裝備遺物後被動觸發 | 受擊爆煙、完美閃避反擊 |
| 臨時事件技 | 當局事件或詛咒給予 | 一次性清場、短期狂暴 |
| Creator 干涉技 | Final Boss 階段臨時封鎖或改寫 | Eraser、重畫場地 |

### 1.2 依功能分類

| 功能 | 定位 | 代表技能 |
|---|---|---|
| 輸出 | 造成主要傷害 | 核心光束、怨火爆燃 |
| 位移 | 穿越危險、追擊、逃跑 | 影遁衝刺、蛛線牽引 |
| 控場 | 拉扯、擊退、定身、打斷 | 管線衝擊、蛛線牽引 |
| 防禦 | 吸收、霸體、減傷 | 吞運葫蘆、鬥氣爆發 |
| 破防 | 專門打盾、甲、蓄力、召喚 | 破甲合擊、核心光束 |
| 資源 | 回怨念、掉落、冷卻管理 | 遺物與被動升級 |

## 2. 技能槽設計

### 2.1 MVP 技能槽

MVP 階段建議：

```text
普攻固定 + 閃避固定 + 主動技能 1 格 + 被動遺物若干
```

原因：

- 手機操作簡單。
- 容易驗證單一 Boss 技能是否好玩。
- UI 不會過度擁擠。
- 可以先測「搶能力」的爽感。

### 2.2 完整版技能槽

完整版可擴充為：

| 槽位 | 功能 |
|---|---|
| 普攻 | Ghost 固定基礎攻擊，可被被動改造。 |
| Dash | 固定閃避，可被遺物改造。 |
| 主動技能 A | Boss 奪取技。 |
| 主動技能 B | 第二個 Boss 奪取技或事件技。 |
| 爆發技能 | 高消耗高回報，可由 Build 決定。 |
| 被動遺物 | 多個局內被動效果。 |

### 2.3 技能槽限制

- 同時可裝備 Boss 主動技數量有限。
- 已取得能力可以在安全區 / 關卡間切換。
- 戰鬥中不開放完整換裝，避免暫停打斷節奏。
- 某些詛咒或 Creator 技能可暫時封鎖一格。

## 4. 技能升級系統

### 4.1 升級出現時機

技能升級可在以下時機出現：

- 小怪房勝利後。
- 精英房勝利後。
- Boss 勝利後。
- 商店購買。
- 事件代價交換。
- 遺物觸發進化。

### 4.2 三選一規則

每次升級給 3 個選項。

選項類型建議：

| 類型 | 比例 | 範例 |
|---|---:|---|
| 直接強化 | 40% | 技能傷害 +20%、冷卻 -1 秒 |
| 功能改造 | 35% | 管線衝擊可破隱、蛛線可拉自己 |
| Build 聯動 | 20% | 火焰命中被束縛敵人時爆炸 |
| 代價強化 | 5% | 傷害大幅提升，但消耗 HP 或增加氣運壓力 |

### 4.3 選項品質

三選一不能出現三個幾乎一樣的數值。

錯誤例：

```text
管線衝擊傷害 +10%
管線衝擊傷害 +15%
管線衝擊傷害 +20%
```

正確例：

```text
管線衝擊範圍加寬
管線衝擊命中隱身敵人時造成破防
管線衝擊冷卻降低，但怨念消耗增加
```

## 5. 技能稀有度

| 稀有度 | 定位 | 內容 |
|---|---|---|
| Common | 基礎增強 | 傷害、冷卻、範圍、消耗。 |
| Rare | 功能變化 | 新增打斷、吸收、束縛、蔓延。 |
| Epic | Build 聯動 | 多技能互動，形成玩法核心。 |
| Legendary | 改變打法 | 技能型態大改，但通常有代價。 |
| Cursed | 詛咒強化 | 很強，但增加風險或氣運壓力。 |

稀有度要影響效果強度，也要影響視覺：

- Common：小框、低光。
- Rare：藍紫光。
- Epic：金紫光。
- Legendary：黑金怨念光。
- Cursed：紅黑裂紋與不安定粒子。

## 6. Build 原型

### 6.1 震地破隱流

核心技能：管線衝擊

玩法：

- 用震波打出隱身 / 分身。
- 以範圍與擊退維持安全距離。
- 對小怪群與忍者系 Boss 有優勢。

推薦遺物：

- 破碎地脈。
- 震盪怨骨。
- 分身驗屍單。

### 6.2 影遁背刺流

核心技能：影遁衝刺

玩法：

- 靠完美穿越攻擊回怨念。
- 從敵人背後觸發暴擊。
- 高操作，高回報。

推薦遺物：

- 背後的黑手。
- 影縫短刃。
- 遲到的主角光環。

### 6.3 穿盾光束流

核心技能：核心光束

玩法：

- 抓敵人蓄力或開盾時蓄光束。
- 對裝甲、護盾、直線站位敵人特別強。
- 缺點是蓄力時容易被圍。

推薦遺物：

- 碎裂藍核。
- 反英雄聚焦鏡。
- 借來的正義光。

### 6.4 破甲連擊流

核心技能：破甲合擊

玩法：

- 多段打斷大型敵人。
- 疊破甲層數後普攻輸出。
- 適合正面壓制，但怕遠程消耗。

推薦遺物：

- 第五個隊友。
- 合體失敗證明書。
- 裝甲稅單。

### 6.5 吸收反吐流

核心技能：吞運葫蘆

玩法：

- 把敵人的投射物變成自己的反擊。
- 對火焰、光彈、飛行道具強。
- 需要掌握朝向與吸收時機。

推薦遺物：

- 空葫蘆保固書。
- 被吞掉的奇蹟。
- 反吐協議。

### 6.6 怨火禁療流

核心技能：怨火爆燃

玩法：

- 以火場限制敵人行動。
- 禁止回血與再生。
- 搭配牽引或定身可形成高傷害區域。

推薦遺物：

- 煉壞的丹爐。
- 禁藥目錄。
- 燒焦的蛛網。

### 6.7 蛛線控制流

核心技能：蛛線牽引

玩法：

- 控制敵人位置。
- 把空中敵人拉下來。
- 把自己拉出危險範圍。

推薦遺物：

- 斷線義警徽章。
- 都市屋簷契約。
- 看不見的手。

### 6.8 霸體鬥氣流

核心技能：鬥氣爆發

玩法：

- 在危險窗口強行輸出。
- 把受擊轉為怨念。
- 適合近戰 Boss，但容易因貪刀死亡。

推薦遺物：

- 爆氣過期券。
- 武道會敗者名單。
- 差一點覺醒證明。

## 7. 技能聯動規則

### 7.1 標籤聯動

技能與遺物都使用標籤互動。

例：

```text
如果敵人帶有 bind 狀態，flame 技能造成額外爆燃。
如果敵人有 armor，core 技能造成額外破盾。
如果玩家剛完美 dash，下一個 shadow 技能冷卻降低。
```

### 7.2 推薦聯動表

| A 技能 | B 技能 / 遺物 | 聯動效果 |
|---|---|---|
| 管線衝擊 | 怨火爆燃 | 裂縫被點燃，形成短火線。 |
| 影遁衝刺 | 核心光束 | 衝刺後 1 秒內光束蓄力加快。 |
| 核心光束 | 破甲合擊 | 破甲敵人被光束命中會爆裂。 |
| 破甲合擊 | 鬥氣爆發 | 爆氣期間合擊段數增加。 |
| 吞運葫蘆 | 核心光束 | 吸收成功後下一發光束追加反吐能量。 |
| 怨火爆燃 | 蛛線牽引 | 被拉進火場的敵人短暫禁錮。 |
| 蛛線牽引 | 管線衝擊 | 拉倒地面後震波必定命中。 |
| 鬥氣爆發 | 怨念爪擊 | 普攻最後一段追加震波。 |

## 8. Build 風險與代價

本作不希望每個 Build 都只是越疊越強。

每種 Build 都要有弱點：

| Build | 強項 | 弱點 |
|---|---|---|
| 震地破隱 | 對地面、分身強 | 對飛行敵人較弱 |
| 影遁背刺 | 高機動、高暴擊 | 操作要求高，失誤容易死 |
| 穿盾光束 | 對護盾裝甲強 | 蓄力容易被打斷 |
| 破甲連擊 | 壓制大型敵人 | 怕遠程與地形干擾 |
| 吸收反吐 | 對投射物強 | 對純近戰敵人收益低 |
| 怨火禁療 | 區域壓制 | 敵人太靈活時難命中 |
| 蛛線控制 | 位置操控強 | 對重型 Boss 牽引弱 |
| 霸體鬥氣 | 硬打窗口強 | 容易誘導玩家貪刀 |

## 10. 技能 UI 顯示

### 10.1 技能卡內容

每張技能卡應顯示：

- 技能名稱。
- 來源 Boss 小圖示。
- 稀有度框。
- 功能標籤。
- 效果短描述。
- 冷卻 / 消耗。
- 相剋提示。

例：

```text
管線衝擊
來源：M先生
標籤：震地 / 破隱 / 擊退
效果：向前打出地面震波，能震出隱身與分身敵人。
相剋：忍者系、地面潛伏敵人
```

### 10.2 三選一頁面文案原則

文案要短、清楚、有黑色幽默。

錯誤：

```text
技能傷害提高 15%，技能半徑提高 10%，對特殊單位有額外判定。
```

正確：

```text
破隱施工
管線衝擊命中隱身或分身敵人時，直接把它們震出來。
「躲？施工隊不同意。」
```

## 11. Creator 對技能系統的干涉

Final Boss Creator 的特色是它可以動到玩家 Build。

### 11.1 Eraser 對技能槽的影響

Eraser 可暫時造成：

| 干涉 | 效果 |
|---|---|
| 技能封鎖 | 隨機一個主動技能短暫不可用。 |
| 投射物清除 | 清除場上玩家投射物。 |
| 地形清除 | 擦掉火場、蛛線、裂縫等持續效果。 |
| 冷卻重畫 | 暫時增加某技能冷卻。 |

### 11.2 反制方式

玩家不是硬吃干涉，而是用前面學會的克制順序反制：

- Creator 使用分身 → 管線衝擊。
- Creator 使用光束 → 影遁衝刺。
- Creator 開盾 → 核心光束。
- Creator 裝甲化 → 破甲合擊。
- Creator 投射火丹 → 吞運葫蘆。
- Creator 牽線控場 → 怨火爆燃。
- Creator 空中蓄氣 → 蛛線牽引。
- Creator 近戰連壓 → 鬥氣爆發。

這場戰鬥等於全遊戲技能考試。

## 12. 平衡原則

### 12.1 不追求完全平均

每個技能不需要在所有場合一樣強。

正確平衡：

```text
某技能在對應敵人非常爽，在其他場合仍有基本用途。
```

錯誤平衡：

```text
所有技能都只是差不多的傷害。
```

### 12.2 防止單一技能通關

方法：

- 敵人抗性。
- 技能冷卻。
- 怨念消耗。
- 地形限制。
- Boss Phase 變化。
- Creator 最終干涉。

### 12.3 強化選擇要有取捨

例：

| 選項 | 好處 | 代價 |
|---|---|---|
| 傷害大增 | 秒小怪 | 冷卻變長 |
| 範圍變大 | 清場強 | 怨念消耗提高 |
| 多段充能 | 操作彈性 | 單次傷害降低 |
| 低血增傷 | 翻盤強 | 風險高 |

## 13. MVP 技能實作建議

第一版只做：

1. Ghost 普攻。
2. Ghost Dash。
3. 管線衝擊。
4. 影遁衝刺。
5. 三選一升級。
6. 10 個遺物。
7. 1 組明確相剋：管線衝擊剋滅影忍者。

MVP 不需要一開始就做完整技能樹。

優先驗證：

- 技能按下去是否好玩。
- 技能命中是否清楚。
- 技能克制是否肉眼能懂。
- 玩家是否願意為了技能改變打法。

## 15. 驗收清單

技能系統完成一輪後檢查：

- 每個技能是否有明確來源 Boss？
- 每個技能是否有不同功能？
- 每個技能是否至少有一個明顯克制目標？
- 三選一是否不只是數值？
- 玩家是否能在 UI 上理解冷卻與消耗？
- 技能特效是否能看出方向與範圍？
- 強技能是否有冷卻、消耗或操作代價？
- 是否存在至少 3 種明顯 Build 原型？
- 是否避免了萬能技能？
- Creator 是否能測試玩家對技能的理解？
