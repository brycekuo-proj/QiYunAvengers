# 15｜小怪、關卡與數值平衡設計 V1

專案：《氣運復仇者》 / QiYun Avengers

用途：固定小怪職責、關卡節奏、難度曲線、血量傷害區間、生成規則、精英戰與每張地圖的敵人配置，避免 Prototype 後期因數值混亂導致體驗失準。

## 0. 平衡總原則

### 0.1 小怪平衡目標

| 目標 | 說明 |
|---|---|
| 可讀 | 攻擊前搖、範圍、彈道都要清楚。 |
| 可躲 | 玩家有時間與空間閃避。 |
| 可反 | 攻擊後有短破綻。 |
| 可學 | 小怪機制要預告 Boss。 |
| 可組合 | 不同小怪放一起會形成新壓力。 |
| 不搶戲 | 小怪不能比 Boss 更複雜。 |

### 0.2 難度來源

本作的難度應該來自：

- 攻擊組合。
- 場地限制。
- 資源壓力。
- 相剋理解。
- 貪刀風險。

不應來自：

- 無預警傷害。
- 血量膨脹。
- 彈幕糊成一團。
- 小怪硬直過高導致玩家無法行動。

## 1. 小怪職責分類

| 類型 | 主要功能 | 血量 | 傷害 | 數量 |
|---|---|---:|---:|---:|
| 雜兵 | 基礎追擊與被擊殺節奏 | 低 | 低 | 多 |
| 近戰兵 | 逼玩家移動 / 防貼臉 | 中 | 中 | 中 |
| 遠程兵 | 形成彈道壓力 | 低～中 | 中 | 中 |
| 輔助兵 | 補血、護盾、召喚、警報 | 低 | 低 | 少 |
| 控場兵 | 緩速、拉扯、陷阱 | 中 | 低～中 | 少 |
| 精英兵 | 小型 Boss 機制 | 高 | 高 | 極少 |

## 2. 小怪 AI 模板

### 2.1 近戰追擊

```text
尋找玩家 → 接近 → 攻擊前搖 → 攻擊 → 後搖 → 重新尋找
```

設計規則：

- 接近速度不要比 Ghost Dash 還誇張。
- 攻擊前搖至少 0.35 秒。
- 一次近戰攻擊後要有 0.4～0.8 秒後搖。

### 2.2 遠程射擊

```text
保持距離 → 瞄準 → 前搖 → 發射 → 換位或停頓
```

設計規則：

- 彈道顏色不可和背景混在一起。
- 同畫面遠程兵過多時自動降低射速。
- 早期遠程彈不可追蹤。

### 2.3 輔助干擾

```text
找隊友 → 施放補助 → 逃跑 / 等待 → 冷卻
```

設計規則：

- 輔助兵本身脆弱。
- 玩家應能判斷要優先擊殺。
- 補血或護盾要有明顯連線 / 圈圈提示。

### 2.4 精英兵

```text
短 Boss 模式 → 2～3 個招式循環 → 破防窗口 → 掉落較好獎勵
```

設計規則：

- 每隻精英只測一個主題。
- 不要同時擁有高血量、高傷害、高機動、高召喚。
- 精英死亡後要有明顯獎勵。

## 3. 數值基準

以下以 `Ghost 初始 HP = 100` 為基準。

### 3.1 小怪傷害

| 類型 | 單次傷害 | 備註 |
|---|---:|---|
| 雜兵觸碰 | 4～6 | 不鼓勵碰撞傷害太高。 |
| 近戰普攻 | 8～12 | 可被打斷或躲開。 |
| 遠程彈 | 7～10 | 彈速清楚。 |
| 輔助攻擊 | 3～6 | 不是主要威脅。 |
| 控場陷阱 | 5～8 | 重點是限制位置。 |
| 精英重擊 | 15～25 | 必須有長前搖。 |

### 3.2 小怪血量

| 類型 | HP | 擊殺時間目標 |
|---|---:|---|
| 低階雜兵 | 20～35 | 1～3 秒 |
| 普通近戰 | 45～70 | 3～6 秒 |
| 普通遠程 | 35～60 | 3～5 秒 |
| 輔助兵 | 30～50 | 2～4 秒 |
| 控場兵 | 50～80 | 4～7 秒 |
| 精英兵 | 180～350 | 20～45 秒 |

### 3.3 Boss 血量倍率

| 關卡段位 | Boss HP 基準 |
|---|---:|
| 早期 | 800～1200 |
| 中期 | 1500～2200 |
| 後期 | 2500～3600 |
| Final | 4500～6500，分 Phase |

MVP 不需追求完整數值，先追求：

```text
玩家在 2～4 分鐘內打完一位 Boss。
```

## 4. 生成規則

### 4.1 同畫面敵人上限

手機畫面建議：

| 敵人類型 | 同時上限 |
|---|---:|
| 小雜兵 | 8～12 |
| 普通近戰 | 4～6 |
| 遠程兵 | 2～4 |
| 輔助兵 | 1～2 |
| 控場兵 | 1～2 |
| 精英兵 | 1 |

### 4.2 Wave 組合

| Wave 類型 | 組合 |
|---|---|
| 教學 Wave | 單一新敵人 2～3 隻。 |
| 基礎 Wave | 近戰 + 少量遠程。 |
| 壓力 Wave | 近戰 + 遠程 + 輔助。 |
| 機制 Wave | 控場 + 特定技能可克制敵人。 |
| 精英 Wave | 精英 + 少量雜兵，不加太多遠程。 |

### 4.3 生成位置

- 不在玩家身上生成。
- 不在螢幕邊界外直接攻擊。
- 新生成敵人要有短暫出現動畫或煙霧提示。
- 遠程兵盡量生成在可接近位置，不放在無法打到的高台。

## 6. 關卡難度曲線

| 階段 | 玩家能力 | 敵人壓力 | 設計目的 |
|---|---|---|---|
| 0～1 | 初始 Ghost | 少量、單機制 | 教操作。 |
| 2～3 | 1～2 個 Boss 技能 | 分身、護盾、光束 | 教相剋。 |

| 6～7 | 多技能 + 遺物 | 火場、牽引、高速 | 考驗反應與組合。 |
| 8 | 成熟 Build | 爆氣、空中、高傷 | 高壓戰鬥。 |

## 7. 房間類型與獎勵

| 房間 | 戰鬥壓力 | 獎勵 |
|---|---|---|
| 普通小怪房 | 低～中 | 怨幣、小補給、小概率遺物。 |

## 8. 動態難度控制

可以做輕量動態調整，但不能偷偷作弊。

### 8.1 可調整項

- 掉落補給稍微增加。
- 小怪 Wave 間隔微調。
- 商店出現回復品機率提高。
- 氣運壓力上升速度放緩。

### 8.2 不應調整項

- Boss 無預警降傷害。
- 玩家命中判定偷偷變大。
- 敵人攻擊突然失準。
- 已顯示的數值偷偷改變。

動態調整要服務體驗，不要破壞玩家信任。

---

## 9. 新手保護

第一局或教學階段可加入：

- 前 2 房補給掉落提高。
- 第一次死亡顯示明確提示。
- 第一次 Boss 大招前播放慢一點的預警。
- 第一次取得 Boss 技能後強制安排能克制的敵人。

新手保護只存在前期，不要讓全遊戲都變簡單。

## 10. 平衡測試指標

### 10.1 單房時間

| 房間 | 目標時間 |
|---|---:|
| 教學房 | 20～40 秒 |
| 普通房 | 45～90 秒 |
| 機制房 | 60～120 秒 |
| 精英房 | 90～180 秒 |
| Boss 房 | 2～4 分鐘 |

### 10.2 玩家死亡原因分類

每次死亡應可歸因：

- 貪刀。
- 沒看前搖。
- 沒先殺輔助。
- 不懂相剋。
- Build 風險太高。
- 走位被地形限制。
- 純數值過低。

如果大量死亡歸因是「看不懂發生什麼」，代表平衡失敗。

## 12. MVP 平衡範圍

第一版只平衡：

```text
怨念甦醒地 → M先生 → 影村訓練場 → 滅影忍者
```

必須驗證：

- Ghost 初始手感。
- 小怪數量上限。
- 管線衝擊是否能破影系小怪。
- M先生戰是否不會過難。
- 滅影忍者是否因管線衝擊產生明顯爽感。

## 13. 驗收清單

平衡完成後檢查：

- 每種小怪是否有單一清楚功能？
- 小怪是否預告 Boss？
- 同畫面是否過亂？
- 遠程攻擊是否可讀？
- 輔助敵人是否值得優先擊殺？
- 精英是否像小型 Boss，而不是血牛？
- 玩家死亡原因是否可理解？
- 每張地圖是否至少有一種新壓力？
- 前期是否沒有太多系統同時教？
- 後期是否真的考驗前面學過的能力？
