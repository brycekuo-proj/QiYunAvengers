# 17｜成長、進程與經濟設計 V1

專案：《氣運復仇者》 / QiYun Avengers

用途：固定單局進程、跨局解鎖、貨幣、商店、掉落、路線選擇、Boss 能力取得與長期收集，確保 Roguelite 結構服務「打英雄 → 搶能力 → 相剋下一位英雄」。

> 本文件接續：
>
> - `11_CORE_GAMEPLAY_COMBAT_DESIGN.md`
> - `12_SKILL_BUILD_SYSTEM_DESIGN.md`
> - `13_ITEM_RELIC_EFFECT_DESIGN.md`
> - `15_ENEMY_STAGE_BALANCE_DESIGN.md`
>
> 經濟系統不是為了把玩家拖久，而是讓每局都有清楚選擇：**現在要安全、要變強，還是要賭更大的復仇？**

---

## 0. 成長系統總原則

### 0.1 兩種成長

| 成長 | 說明 | 範例 |
|---|---|---|
| 局內成長 | 當局有效，死亡後重置 | 遺物、技能升級、怨幣、消耗品。 |
| 跨局進程 | 長期解鎖，不直接破壞平衡 | Boss 圖鑑、技能解鎖記錄、起始選項、外觀、難度模式。 |

### 0.2 設計底線

- 不能讓跨局永久數值堆太高，否則後期失去 Roguelite 判斷。
- Boss 技能取得要和擊敗 Boss 綁定，不靠抽卡。
- 玩家死亡後應保留知識、圖鑑與少量解鎖，不保留當局無限強度。
- 商店提供選擇，不是必買清單。

## 1. 單局進程

### 1.1 標準流程

```text
選擇初始怨念核心
  ↓
地圖 0 / 起始房
  ↓
普通房、事件房、商店、精英房
  ↓
Boss 房
  ↓
奪取 Boss 技能
  ↓
選下一張地圖 / 下一位英雄
  ↓
重複 3～5 次
  ↓
Final Boss / 死亡結算
```

### 1.2 單局長度

| 版本 | 目標時間 |
|---|---:|
| MVP | 10～20 分鐘 |
| Vertical Slice | 15～30 分鐘 |
| 完整版短局 | 25～45 分鐘 |
| 高難挑戰 | 45～60 分鐘 |

## 2. 地圖節點結構

### 2.1 節點類型

| 節點 | 圖示方向 | 內容 | 獎勵 |
|---|---|---|---|
| 普通戰鬥 | 小劍 / 怨爪 | 小怪 Wave | 怨幣、補給。 |
| 精英戰 | 骷髏星 / 裂冠 | 強化敵人 | 稀有遺物、技能升級。 |
| 事件 | 問號 / 破卷軸 | 風險選擇 | 遺物、詛咒、回血、情報。 |
| 商店 | 怨幣袋 | 買賣道具 | 遺物、消耗品、重骰。 |
| 休息 | 破營火 | 回血或強化 | 小恢復、升級。 |
| Boss | 英雄徽記裂開 | Boss 戰 | 固定 Boss 技能。 |
| Creator | 白頁王座 | Final Boss | 結局。 |

### 2.2 路線選擇

一層地圖可給 2～3 條路：

```text
安全路：普通房多，獎勵低。
風險路：精英 / 事件多，獎勵高。
商店路：經濟消耗，補 Build。
```

玩家選擇路線時要知道大方向，不要完全盲抽。

## 3. 貨幣系統

### 3.1 局內貨幣：怨幣

怨幣用途：

- 商店購買遺物。
- 購買補給。
- 重骰升級選項。
- 解除詛咒。
- 事件中賄賂或交換情報。

怨幣來源：

- 擊殺小怪。
- 打破可互動物件。
- 精英戰獎勵。
- 特定遺物。
- 事件選擇。

### 3.2 跨局貨幣：殘響

殘響用途偏解鎖，不直接讓角色永久大幅變強。

可解鎖：

- 起始怨念核心。
- 圖鑑情報。
- 訓練場 Boss 練習。
- 新外觀。
- 新事件池。
- 起始道具候選。

不建議用殘響直接買：

- 永久攻擊力 +50%。
- 永久 HP 翻倍。
- 開局直接拿 Legendary 遺物。

### 3.3 特殊資源：氣運碎片

氣運碎片由 Boss、精英或高風險事件掉落。

用途：

- 解鎖 Boss 技能圖鑑詳情。
- 開放某 Boss 技能的起始變體。
- 解鎖 Creator 相關事件。
- 開啟高難路線。

## 4. 局內獎勵規則

### 4.1 房間獎勵

| 房間 | 基礎獎勵 | 額外獎勵 |
|---|---|---|
| 普通房 | 怨幣 + 小補給 | 小概率 Common 遺物。 |
| 精英房 | 怨幣 + 三選一 | Rare 以上遺物。 |
| 事件房 | 依選項 | 詛咒、回血、情報、特殊道具。 |
| 商店 | 無免費獎勵 | 可花怨幣取得道具。 |
| Boss 房 | 固定技能 | 技能升級 / 遺物二選一。 |

### 4.2 三選一權重

| 進度 | Common | Rare | Epic | Legendary | Cursed |
|---|---:|---:|---:|---:|---:|
| 前期 | 65% | 30% | 5% | 0% | 低 |
| 中期 | 35% | 45% | 18% | 2% | 中 |
| 後期 | 15% | 35% | 35% | 10% | 中高 |
| Creator 前 | 5% | 25% | 40% | 20% | 高 |

Cursed 不一定稀有，但一定要讓玩家知道代價。

## 5. 商店設計

### 5.1 商店商品欄位

基礎商店建議 5 格：

| 格位 | 商品 |
|---|---|
| 1 | 回血消耗品。 |
| 2 | 回怨念消耗品。 |
| 3 | 隨機 Common / Rare 遺物。 |
| 4 | 技能升級券或重骰券。 |
| 5 | 高價神秘商品 / 詛咒商品。 |

### 5.2 價格基準

| 商品 | 價格方向 |
|---|---:|
| 小補給 | 20～40 怨幣 |
| 中補給 | 50～80 怨幣 |
| Common 遺物 | 80～120 怨幣 |
| Rare 遺物 | 140～220 怨幣 |
| Epic 遺物 | 260～420 怨幣 |
| 重骰券 | 60～120 怨幣 |
| 移除詛咒 | 180～350 怨幣 |
| 神秘垃圾桶 | 80～300 怨幣，依進度變動 |

### 5.3 商店黑色幽默

```text
「歡迎光臨。英雄有贊助商，你有怨幣嗎？」
「本店支援復仇分期，不支援退款。」
「買不起不是問題，活不到下間店才是問題。」
```

## 6. Boss 技能解鎖

### 6.1 第一次擊敗 Boss

第一次擊敗某 Boss：

```text
解鎖該 Boss 技能 → 加入後續局內可能起始選項 → 開啟圖鑑資料 → 解鎖相關遺物池
```

### 6.2 重複擊敗 Boss

重複擊敗可給：

- 技能升級選項。
- 氣運碎片。
- Boss 專屬遺物。
- 高難變體進度。

不要讓重複擊敗只變成刷數字。

### 6.3 技能起始選擇

當玩家曾擊敗過某 Boss，可在開局選擇少量起始變體：

| 起始變體 | 說明 |
|---|---|
| 初始怨念爪 | 完全原始，獎勵較高。 |
| 破損管線核心 | 開局獲得弱化管線衝擊。 |
| 暗影殘步 | 開局 Dash 變強，但 HP 低。 |
| 碎裂藍核 | 開局蓄力強，但冷卻長。 |

起始 Boss 技能應為弱化版，避免跳過前期成長。

## 7. 跨局進程

### 7.1 圖鑑

圖鑑記錄：

- 已遇到 Boss。
- 已擊敗 Boss。
- 已被哪招殺死。
- 相剋提示。
- 小怪資料。
- 陷阱資料。
- 遺物資料。

圖鑑不直接給玩家「唯一正解」，而是給世界知識與風險提示。

### 7.2 訓練場

訓練場可讓玩家練：

- 已遇過的 Boss。
- 已解鎖技能。
- 已看過的小怪。
- 陷阱閃避。

訓練場不掉正式獎勵，只用來降低挫折。

### 7.3 外觀收藏

可做長期目標：

- Ghost 斗篷顏色。
- 怨念眼睛形狀。
- 技能黑化特效變體。
- 勝利 / 死亡姿勢。

外觀不影響戰鬥數值。

## 8. 事件經濟

事件選項要有明確成本。

| 事件選項 | 收益 | 代價 |
|---|---|---|
| 拿走英雄補給 | 回血 / 遺物 | 氣運壓力上升。 |
| 打碎神像 | 怨幣 / 氣運碎片 | 下一房小怪變多。 |
| 賣掉記憶 | 得到 Rare 遺物 | 圖鑑提示暫時模糊。 |
| 借命復仇 | 大幅增傷 | 失去最大 HP。 |
| 放過小怪 | 降低氣運壓力 | 少拿獎勵。 |
| 假裝正義 | 商店折扣 | Boss 發現後開場護盾。 |

---

## 9. 氣運壓力經濟

氣運壓力是一種非貨幣資源。

### 9.1 上升來源

- 拿詛咒遺物。
- 使用假主角光環。
- 連續擊殺正義支援者。
- 破壞英雄象徵物。
- 事件中選擇高收益低道德選項。

### 9.2 下降來源

- 放棄獎勵。
- 犧牲遺物。
- 打破 Creator 草稿頁。
- 完成高風險機制房。
- 商店購買「氣運平衡」服務。

### 9.3 高氣運壓力效果

| 壓力 | 效果 |
|---|---|
| 低 | 正常。 |
| 中 | Boss 更早使用支援招。 |
| 高 | 小怪支援增加，Boss 開場有小護盾。 |
| 爆表 | 下一位 Boss 觸發特殊氣運反撲。 |

## 10. 難度模式

### 10.1 基礎模式

- 給完整教學。
- 補給較正常。
- 氣運壓力成長較慢。
- 適合初次玩家。

### 10.2 復仇模式

- 標準 Roguelite 難度。
- 氣運壓力正常。
- Boss Phase 完整。

### 10.3 命運不公模式

- 高難模式。
- 氣運壓力更快。
- 精英更多。
- Creator 的 Eraser 更頻繁。
- 掉落更好。

## 11. 結算畫面

### 11.1 死亡結算

顯示：

- 擊敗敵人數。
- 打到第幾張地圖。
- 擊敗 Boss。
- 取得技能。
- 主要死亡原因。
- 本局 Build 標籤。
- 獲得殘響。
- 解鎖圖鑑項目。

死亡句風格：

```text
「你不是沒有努力，只是世界比較偏心。」
「復仇進度：很可惜，還是零。」
「這次你學會了：不要在火場裡讀技能說明。」
```

### 11.2 勝利結算

顯示：

- 本局擊敗 Boss 順序。
- 最常用技能。
- 相剋成功次數。
- 拿過的詛咒。
- 是否反制 Eraser。
- 解鎖結局或外觀。

## 12. MVP 進程範圍

第一版只做：

| 系統 | MVP 內容 |
|---|---|
| 局內貨幣 | 怨幣。 |
| 商店 | 5 格商品。 |
| 跨局貨幣 | 殘響，只做記錄或簡單解鎖。 |
| Boss 技能 | M先生、滅影忍者。 |
| 遺物 | 15～20 個。 |
| 地圖路線 | 簡單 2 條路。 |
| 結算 | 死亡原因 + 本局 Build。 |

不要先做複雜 Meta 升級樹。

## 14. 驗收清單

進程與經濟完成後檢查：

- 玩家每局是否有不同路線選擇？
- Boss 技能是否仍是最大獎勵？
- 商店是否有取捨，而不是必買？
- 怨幣是否不會太多或太少？
- 跨局進程是否不會破壞平衡？
- 死亡後是否有學習與圖鑑回饋？
- 氣運壓力是否可理解？
- 詛咒是否有明確代價？
- MVP 是否沒有過度複雜？
- 玩家是否想再開一局？
