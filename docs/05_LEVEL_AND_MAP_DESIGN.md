# 05｜關卡設計與地圖美術

## 設計目的

《氣運復仇者》的地圖不是英雄登場前的展示房，而是讓玩家在見到 Boss 前，先透過地形、小怪、精英波與場景物件讀懂這名英雄的戰鬥語言。

MVP 可以先少做地圖，但每一張正式 Boss 地圖都必須是完整可玩關卡。正式關卡要讓玩家經歷「遭遇 → 理解 → 被壓迫 → 找到弱點 → 進 Boss 房驗證」的完整節奏。

## 關卡規模修正

### 核心規則

MVP 可以只先做 0～3 四張地圖，但不能把 1～3 做成只有一兩隻小怪加 Boss 的展示房。

每張正式 Boss 地圖必須符合以下規模：

- **30～50 名正派小角色**。
- **每關固定 3 種小角色**，讓玩家能讀懂本關語言，而不是被雜亂敵人淹沒。
- **8～12 波小怪配置**，以波次控制節奏與學習曲線。
- **小怪區約 5～8 分鐘**。
- **Boss 戰約 2～4 分鐘**。
- **單關總長約 8～12 分鐘**。
- **Boss 前必須有補給點或弱點提示**，讓玩家知道下一場不是盲打。

### MVP 第一階段範圍

第一階段先做：

1. **0 怨念甦醒地**：教學地圖。
2. **1 紅帽管線城**：M先生完整關卡。
3. **2 影村訓練場**：滅影忍者完整關卡。
4. **3 藍核防衛基地**：U-man 完整關卡。

其中 1～3 都必須是完整關卡：每張 30～50 名正派小角色、固定 3 種小角色、8～12 波小怪、有補給點或弱點提示、有正式 Boss 房。不接受只打一兩隻小怪就進 Boss。

---

## 標準關卡流程

每張正式 Boss 地圖使用同一套節奏骨架：

```text
入口區
→ 小怪波 1～3
→ 中段區
→ 小怪波 4～7
→ 精英波 / 支援波
→ 小怪波 8～12
→ 補給點 / 弱點提示
→ Boss 房
```

### 節奏說明

- **入口區**：用背景、第一批敵人與安全物件展示本關主題。
- **小怪波 1～3**：只出 1～2 種敵人，讓玩家學會基本威脅。
- **中段區**：加入本關地形機制，但不立刻疊滿敵人。
- **小怪波 4～7**：三種小角色開始混合，讓玩家理解相剋工具。
- **精英波 / 支援波**：把本關 Boss 的其中一個機制縮小成小怪版本。
- **小怪波 8～12**：完整混合測驗，檢查玩家是否真的會用現有能力處理本關。
- **補給點 / 弱點提示**：給回血、能量、一次性道具、Boss 弱點壁畫、殘骸或台詞提示。
- **Boss 房**：移除多餘雜物，保留最關鍵的地形與機制，讓玩家專心讀 Boss。

## 地圖美術規則

### 1. 橫向 2D 可讀性優先

所有地圖美術都必須先服務橫向 2D 戰鬥。背景可以豐富，但前景、平台、危險區、可互動物件、補給物件必須一眼分得出來。

### 2. 每關只抓 3～5 個大型記憶點

不要把所有靈感都塞進同一張地圖。每關選 3～5 個玩家會記住的大型元素即可，例如：巨型管線、黑色訓練木樁、藍核反應爐、鋼筋吊臂、七色山壁。

### 3. 地圖物件要服務玩法

裝飾物件最好能兼具玩法功能，例如：

- 管線可噴氣、可破壞、可當平台。
- 訓練木樁可遮擋飛鏢、也可能被斬斷。
- 能量柱可充能，也會在過載時爆裂。
- 鋼筋吊臂可形成移動障礙。
- 葫蘆藤可當攀爬路線，也可能束縛玩家。

### 4. Boss 房比小怪區更乾淨

小怪區可以用更多前景物、地形轉折與節奏變化。Boss 房應該更乾淨，只保留：

- Boss 主要移動路線。
- 玩家閃避空間。
- 1～2 個核心場地機制。
- 清楚的危險提示。

### 5. 聯想度來自關卡語言，不直接照搬

地圖可以有「正義英雄世界被怨念入侵」的聯想，但不能直接照搬既有 IP 的名稱、Logo、招式名、經典姿勢、音樂、UI、地標構圖或可辨識品牌符號。

本作應使用自己的關卡語言：圓潤 Q 版積木角色、怨念塗鴉、破碎英雄宣傳牌、被污染的補給箱、黑紫色怨氣裂縫、Ghost 的惡作劇式復仇痕跡。

# 地圖詳細設計

## 0｜怨念甦醒地：教學地圖

### 對應 Boss

無正式 Boss。結尾可安排「怨念核心」或「假想英雄投影」作為教學收束戰。

### 主題定位

玩家第一次理解自己不是英雄，而是被英雄故事碾過去的怨念集合。這張圖教會移動、攻擊、閃避、吸收殘念、短暫使用能力碎片。

### 地圖美術

大型記憶點：

1. 破碎舞台般的黑色空地。
2. 倒插在地上的英雄宣傳牌。
3. 飄浮的怨念碎片。
4. 地面裂開的黑紫色光縫。
5. 遠景中被撕碎的勝利布幕。

整體視覺是「英雄故事的背面」。場景不直接指向任何單一英雄，而是由敗者墓碑、破碎獎盃、被踩扁的反派面具構成。

### 地形機制

- 安全平台教學移動與跳躍。
- 怨念裂縫教玩家閃避危險區。
- 可吸收的殘念球教玩家回復與能量取得。
- 假想敵投影教基礎攻擊與攻擊前搖。

### 小角色數量配置

教學圖不套用正式 Boss 地圖的 30～50 名規模，建議 10～18 名投影敵人即可。

- 投影巡邏者：6～8 名。
- 投影射手：3～5 名。
- 投影守衛：1～3 名。

### 波次節奏

- 波 1：單一巡邏者，教攻擊。
- 波 2：兩名巡邏者，教移動中攻擊。
- 波 3：射手登場，教閃避。
- 波 4：守衛登場，教繞背或蓄力。
- 波 5：混合小測驗。
- 波 6：怨念核心收束戰。

### Boss 房設計

不是正式 Boss 房，而是怨念核心空間。場地乾淨，中央有一顆會召喚投影的核心，左右各一個安全補給點。核心每次破裂都吐出一段 Ghost 的身世提示。

### 對應技能相剋

- Ghost Dash 可穿過巡邏者衝撞。
- 基礎攻擊可清投影射手。
- 蓄力或繞背可處理投影守衛。

## 1｜紅帽管線城：M先生

### 對應 Boss

M先生。

### 主題定位

第一張正式英雄關。這張圖教玩家處理「工具型英雄」與可破壞場景機關。M先生不是單純近戰 Boss，而是會利用管線、扳手裝置、壓力閥與維修兵支援的城市守護者。

### 地圖美術

大型記憶點：

1. 巨型紅色管線橫跨背景。
2. 會噴蒸氣的壓力閥。
3. 貼滿英雄維修標語的牆面。
4. 下水道圓形閘門。
5. Boss 房中央的大型主水閥平台。

色彩以紅、橘、鐵灰為主，加入被 Ghost 污染後的黑紫色漏液。所有標誌使用原創圖形，不使用既有遊戲或玩具品牌符號。

### 地形機制

- 蒸氣管線會週期噴發，形成短暫封路。
- 壓力閥可被攻擊關閉，清出安全路線。
- 圓形管道會吐出小怪，形成波次入口。
- 可破壞扳手機關能提前阻斷支援波。

### 小角色數量配置

總量建議 36～42 名，固定 3 種：

| 小角色 | 數量 | 功能 |
| --- | ---: | --- |
| 管線維修兵 | 16～18 | 基礎近戰，教玩家讀前搖。 |
| 壓力閥投手 | 10～12 | 投擲小型壓力罐，製造落點警示。 |
| 盾牌水管工 | 8～12 | 舉盾推進，預告 M先生的防禦與破盾需求。 |

### 波次節奏

- 波 1：2 名管線維修兵。
- 波 2：3 名管線維修兵 + 1 名壓力閥投手。
- 波 3：2 名壓力閥投手，地形加入蒸氣噴口。
- 波 4：4 名管線維修兵 + 1 名盾牌水管工。
- 波 5：2 名盾牌水管工 + 2 名投手。
- 波 6：維修兵從兩側管道進場，訓練背後警覺。
- 波 7：蒸氣噴口與盾牌推進混合。
- 精英波：大型閥門守衛，持盾並召喚投手支援。
- 波 8：維修兵群壓迫。
- 波 9：投手遠程封位。
- 波 10：三種敵人混合，並出現可破壞機關。

### Boss 房設計

Boss 房是主水閥控制室。地圖乾淨，中央一個大圓形閥門平台，左右兩側各有蒸氣噴口。M先生會敲擊地面讓管線震動，也會呼叫短暫維修支援。

Boss 前補給點放在「壓力維修站」，旁邊用破裂壁畫提示：M先生蓄力修復管線時，攻擊主水閥可以讓他短暫失衡。

### 對應技能相剋

- Ghost 基礎 Dash 可穿過蒸氣噴口間隙。
- 擊敗 M先生後取得的工具衝擊能力可破壞裝置、打斷蓄力、擊碎部分護盾。
- M先生能力後續可剋制藍核防衛基地的能量護盾與固定炮台。

## 2｜影村訓練場：滅影忍者

### 對應 Boss

滅影忍者。

### 主題定位

第二張正式英雄關。重點是高速、分身、暗器、真假路線與視線干擾。玩家要學會不要只追本體，而是用場地提示和範圍手段逼出真正威脅。

### 地圖美術

大型記憶點：

1. 黑木訓練樁陣列。
2. 月光下的紙門剪影。
3. 懸掛的鈴鐺陷阱。
4. 影子滑行的屋簷路線。
5. Boss 房的圓形月台與四面影門。

色彩以深藍、黑、灰白月光為主。影子是玩法提示，不只是裝飾；真正敵人落地時影子會略重，假分身影子較淡。

### 地形機制

- 訓練樁可擋暗器，也會被精英敵人斬斷。
- 紙門後會出現敵人剪影，玩家可提前判斷進場方向。
- 鈴鐺陷阱被碰到會引來額外支援，但也可誘導敵人觸發。
- 屋簷平台提供上下層路線，讓高速敵人更有壓迫感。

### 小角色數量配置

總量建議 34～44 名，固定 3 種：

| 小角色 | 數量 | 功能 |
| --- | ---: | --- |
| 影步學徒 | 14～18 | 快速近戰，教玩家抓衝刺後破綻。 |
| 暗器投手 | 10～12 | 遠程封位，配合紙門剪影提示。 |
| 分身術士 | 8～14 | 製造假目標，預告 Boss 分身機制。 |

### 波次節奏

- 波 1：2 名影步學徒，教衝刺後硬直。
- 波 2：影步學徒 + 暗器投手。
- 波 3：紙門剪影預告暗器方向。
- 波 4：分身術士首次登場，只有 1 真 1 假。
- 波 5：屋簷上下層混戰。
- 波 6：暗器投手在高處封位。
- 波 7：分身術士 + 影步學徒逼玩家識別真身。
- 精英波：影門隊長，短暫隱身後從玩家背後出現。
- 波 8：鈴鐺陷阱區，敵人與陷阱共同施壓。
- 波 9：三種敵人混合，但數量不爆量。
- 波 10：高低差與分身混合測驗。
- 波 11：Boss 前短波，讓玩家練習用範圍或衝擊逼出真身。

### Boss 房設計

Boss 房是月下訓練場。場地中間乾淨，四面有影門，滅影忍者會從影門進出並留下分身。地面上用淡色月影標出真身落點，玩家能靠觀察破解，而不是靠 UI 直接標答案。

Boss 前補給點是「破碎忍具架」，提示：分身不吃重擊硬直，真身被工具衝擊或範圍震盪命中會短暫顯形。

### 對應技能相剋

- M先生的工具衝擊能力可震開分身，逼真身顯形。
- 滅影忍者能力可作為短距離影步，後續剋制鋼筋戰隊工廠的壓迫式包圍與七色葫蘆山的藤蔓束縛。

## 3｜藍核防衛基地：U-man

### 對應 Boss

U-man。

### 主題定位

第三張正式英雄關。重點是能量護盾、直線光束、飛行壓制與基地防衛系統。玩家要學會利用破盾、打斷蓄力與直線位移處理高機動英雄。

### 地圖美術

大型記憶點：

1. 巨型藍色核心反應爐。
2. 白色防衛牆與紅色警戒線。
3. 懸浮能量柱。
4. 過載後裂開的透明護盾門。
5. Boss 房中央的藍核充能塔。

色彩以白、藍、紅作為乾淨英雄感，再用黑紫怨氣污染邊角。基地不能像現成超級英雄總部，應以原創幾何防衛語言呈現。

### 地形機制

- 能量門需要破盾能力或等待過載間隙通過。
- 懸浮炮台會發射直線警示光束。
- 核心充能柱可被打爆，短暫癱瘓護盾敵人。
- 部分平台會因能量過載上下移動。

### 小角色數量配置

總量建議 38～48 名，固定 3 種：

| 小角色 | 數量 | 功能 |
| --- | ---: | --- |
| 藍核守衛 | 16～20 | 基礎近戰與格擋，教破盾節奏。 |
| 光束巡邏機 | 10～14 | 直線雷射封位，預告 Boss 光束。 |
| 充能支援員 | 8～14 | 替敵人補護盾，逼玩家優先處理支援。 |

### 波次節奏

- 波 1：2 名藍核守衛。
- 波 2：藍核守衛 + 1 台光束巡邏機。
- 波 3：光束巡邏機教玩家看紅線預警。
- 波 4：充能支援員首次登場。
- 波 5：守衛被支援員套盾，教優先擊殺。
- 波 6：移動平台 + 光束封位。
- 波 7：護盾門前混合波，要求玩家用 M先生能力破裝置。
- 精英波：藍核隊長，會短暫升空並召喚巡邏機。
- 波 8：光束與支援員混合。
- 波 9：守衛群 + 充能柱。
- 波 10：三種敵人完整混合。
- 波 11：Boss 前過載測驗，玩家要打爆充能柱清場。

### Boss 房設計

Boss 房是藍核充能塔。中央有一根會週期充能的能量柱，左右留出足夠閃避空間。U-man 會在地面近戰、空中俯衝、直線蓄力光束之間切換。

Boss 前補給點是「故障充能站」，旁邊以燒黑的護盾門提示：M先生工具衝擊可打斷充能柱，滅影忍者影步可穿越直線光束後的安全縫隙。

### 對應技能相剋

- M先生能力可破壞充能柱與護盾門。
- 滅影忍者影步可閃過直線光束並貼近空檔。
- U-man 能力可作為直線能量衝刺，後續剋制鋼筋戰隊工廠的密集隊形與異火煉藥宗的火牆空檔。

## 4｜鋼筋戰隊工廠：鋼筋戰士

### 對應 Boss

鋼筋戰士。

### 主題定位

中期團隊壓迫關。這張圖強調隊形、霸體、工廠機械、壓扁路線與支援小隊。玩家面對的不是單一英雄，而是被組織化訓練的正派戰隊。

### 地圖美術

大型記憶點：

1. 巨型鋼筋吊臂。
2. 熱熔火花背景。
3. 移動輸送帶。
4. 鋼筋束形成的臨時掩體。
5. Boss 房的壓力鍛造平台。

整體偏橘紅、鐵灰、深黑，讓玩家一眼知道「重、防禦、壓迫」。

### 地形機制

- 吊臂會橫向移動，形成壓迫牆。
- 輸送帶會改變玩家與敵人的相對距離。
- 鋼筋束可破壞，也可被敵人舉起當盾。
- 鍛造機落下前有明顯陰影提示。

### 小角色數量配置

總量建議 40～50 名，固定 3 種：

| 小角色 | 數量 | 功能 |
| --- | ---: | --- |
| 鋼筋步兵 | 18～22 | 慢速高韌性，製造前排壓力。 |
| 吊臂操作者 | 8～12 | 啟動地形機關，逼玩家處理後排。 |
| 焊光支援手 | 10～16 | 放置短暫火花牆，限制走位。 |

### 波次節奏

8～12 波以「前排推進 → 後排機關 → 隊形混合」逐步加壓。前半段讓玩家熟悉輸送帶，中段加入吊臂，後段用鋼筋步兵護住支援手，逼玩家使用高速位移或直線衝刺切後排。

### Boss 房設計

Boss 房是鍛造平台。左右各有一個吊臂軌道，中間是鋼筋戰士的主戰場。Boss 會舉盾推進、召喚短暫戰隊隊形、利用鍛造機壓縮玩家空間。

Boss 前提示：影步可繞過隊形後排，U-man 直線衝刺可切開密集隊列。

### 對應技能相剋

- 滅影忍者影步可繞背處理支援手。
- U-man 能量衝刺可穿透直線隊形。
- 鋼筋戰士能力可成為短暫霸體或鋼筋反擊，後續剋制蛛網都市天台的拉扯陷阱。

## 5｜七色葫蘆山：葫蘆爺

### 對應 Boss

葫蘆爺。

### 主題定位

多屬性變化關。玩家在同一張地圖內面對七色山壁、葫蘆藤、屬性果實與變化型敵人，但正式小角色仍固定 3 種，避免規則混亂。

### 地圖美術

大型記憶點：

1. 七色分層山壁。
2. 巨型葫蘆藤橋。
3. 會滴落彩色液體的葫蘆果。
4. 山洞內的怨念泉。
5. Boss 房的七色葫蘆祭壇。

美術重點是童話感被怨念污染，不使用任何既有動畫的角色造型或標誌。

### 地形機制

- 葫蘆藤會伸縮，改變平台長度。
- 彩色液體落點會留下短暫地面效果。
- 山壁顏色代表地形狀態，例如彈跳、緩速、滑行。
- 怨念泉可短暫反轉某些地形效果。

### 小角色數量配置

總量建議 36～46 名，固定 3 種：

| 小角色 | 數量 | 功能 |
| --- | ---: | --- |
| 葫蘆藤童 | 14～18 | 近戰束縛，教玩家切斷藤蔓。 |
| 彩液投手 | 10～14 | 改變地面狀態。 |
| 山壁守靈 | 10～14 | 依地形顏色改變防禦或移動方式。 |

### 波次節奏

前段只讓玩家認識藤蔓，中段加入彩液地面效果，後段讓山壁守靈與地形同步變化。精英波可安排「七色守靈」，會短暫切換場地顏色。

### Boss 房設計

Boss 房是七色葫蘆祭壇。場地要乾淨，最多保留兩種當前地形狀態。葫蘆爺會切換顏色階段，但每次只改變一個核心規則，避免玩家讀不懂。

Boss 前提示：影步可脫離藤蔓束縛，鋼筋霸體可硬吃短暫拉扯，U-man 衝刺可穿過彩液危險區。

### 對應技能相剋

- 滅影忍者影步剋藤蔓束縛。
- 鋼筋戰士霸體剋短暫拉扯。
- 葫蘆爺能力可成為地形變化或屬性葫蘆，後續剋制異火煉藥宗的單一火場壓力。

## 6｜異火煉藥宗：消炎

### 對應 Boss

消炎。

### 主題定位

持續場地壓力關。重點是火焰地面、丹爐爆裂、藥粉雲與持續傷害。玩家要學會控制走位節奏，不是只靠衝刺硬闖。

### 地圖美術

大型記憶點：

1. 巨型丹爐。
2. 浮空火種。
3. 煉藥宗門石階。
4. 爆裂藥罐倉庫。
5. Boss 房的三環火焰陣。

色彩以赤橙、紫煙、焦黑為主。火焰要有清楚邊界，避免特效遮住角色。

### 地形機制

- 丹爐會週期噴火，火線有明顯預警。
- 藥粉雲遇火會爆，玩家也能誘導炸敵人。
- 火種可被攻擊推動，成為臨時場地工具。
- 部分地面會短暫燃燒，限制停留時間。

### 小角色數量配置

總量建議 38～48 名，固定 3 種：

| 小角色 | 數量 | 功能 |
| --- | ---: | --- |
| 火童 | 16～20 | 近戰追擊並留下短火痕。 |
| 藥罐投手 | 10～14 | 投擲爆裂藥罐。 |
| 丹爐護法 | 8～14 | 開啟場地噴火，需優先打斷。 |

### 波次節奏

前段先教火痕不能久站，中段加入藥罐爆炸與誘導爆炸，後段由丹爐護法控制場地節奏。精英波可安排「異火護法」，需要玩家打斷蓄火。

### Boss 房設計

Boss 房是三環火焰陣。場地清楚分成內、中、外三圈，消炎會在不同火圈之間切換。Boss 房不能塞太多裝飾，重點是火圈邊界與安全縫隙。

Boss 前提示：葫蘆地形能力可短暫改變燃燒地面，U-man 衝刺可穿過火線空檔，M先生衝擊可打斷丹爐蓄火。

### 對應技能相剋

- 葫蘆爺能力可改變或淨化部分地面狀態。
- M先生能力可打斷丹爐與蓄火。
- 消炎能力可成為持續火場，後續剋制蛛網都市天台的大量蛛絲路線。

## 7｜蛛網都市天台：失敗的面

### 對應 Boss

失敗的面。

### 主題定位

垂直移動與陷阱關。這張圖是都市高樓、蛛網天台、廣告牌與繩索陷阱的混合。玩家需要處理上下層敵人、拉扯、黏著與突襲。

### 地圖美術

大型記憶點：

1. 霓虹天台。
2. 巨型蛛網橫跨樓間。
3. 破碎英雄廣告牌。
4. 吊掛空調與水塔平台。
5. Boss 房的圓形天台蛛網場。

色彩以夜色、霓虹、白色蛛絲與黑紫怨念為主。蛛絲是危險物件，要和背景線條清楚區分。

### 地形機制

- 蛛絲地面會緩速。
- 吊掛蛛網會把玩家拉向固定點。
- 高低平台讓遠程敵人有視角優勢。
- 可破壞廣告牌會砸落並清掉部分蛛網。

### 小角色數量配置

總量建議 34～44 名，固定 3 種：

| 小角色 | 數量 | 功能 |
| --- | ---: | --- |
| 蛛絲巡行者 | 14～18 | 快速攀爬近戰。 |
| 網彈射手 | 10～14 | 發射緩速蛛網彈。 |
| 天台伏擊者 | 8～12 | 從高處突襲，逼玩家注意垂直空間。 |

### 波次節奏

前段教緩速蛛絲，中段加入高低平台與網彈射手，後段安排伏擊者從廣告牌後出現。精英波是「裂面捕手」，能把玩家拉進蛛網區。

### Boss 房設計

Boss 房是都市最高天台。中央蛛網區、左右安全平台、上方兩個可破壞廣告牌。失敗的面會快速貼牆、射網、拉人、短暫複製玩家移動軌跡。

Boss 前提示：鋼筋霸體可抵抗拉扯，消炎火場可燒掉蛛網，影步可脫離黏著區。

### 對應技能相剋

- 鋼筋戰士能力剋拉扯。
- 消炎火場剋蛛網地形。
- 失敗的面能力可成為蛛網機動或拉扯控制，後續剋制鬥氣武道星的高速突進。

## 8｜鬥氣武道星：吾空

### 對應 Boss

吾空。

### 主題定位

高速近戰壓迫關。玩家面對連段、衝刺、跳躍追擊與蓄氣爆發。這張圖要讓玩家感覺敵人很強，但所有攻擊仍有清楚前搖。

### 地圖美術

大型記憶點：

1. 懸浮武道岩台。
2. 環形鬥氣氣流。
3. 破碎星空背景。
4. 訓練用重力石。
5. Boss 房的圓形武道星核場。

美術使用原創武道星球語言，不使用既有角色服裝、髮型、姿勢或招式名稱。

### 地形機制

- 鬥氣氣流會推動玩家或敵人。
- 重力石會短暫改變跳躍與下落速度。
- 岩台會在被重擊後碎裂。
- 蓄氣區域會強化敵人，也可被玩家破壞。

### 小角色數量配置

總量建議 38～48 名，固定 3 種：

| 小角色 | 數量 | 功能 |
| --- | ---: | --- |
| 鬥氣拳徒 | 16～20 | 快速近戰連段。 |
| 氣彈學徒 | 10～14 | 遠程氣彈與蓄力。 |
| 重力修行者 | 8～14 | 改變局部重力，控制平台節奏。 |

### 波次節奏

前段只出拳徒，教玩家讀連段結尾；中段加入氣彈封位與重力區；後段三種敵人混合，讓玩家利用拉扯、火場或破盾能力創造反擊空檔。精英波是「鬥氣師兄」，會蓄氣後連續突進。

### Boss 房設計

Boss 房是圓形武道星核場。場地幾乎無雜物，只保留兩個會改變重力的星核石。吾空會連段、跳躍下砸、蓄氣爆發與高速突進。

Boss 前提示：失敗的面蛛網可限制高速突進，鋼筋霸體可扛住短連段後反擊，M先生衝擊可打斷蓄氣。

### 對應技能相剋

- 失敗的面能力剋高速突進。
- M先生能力可打斷蓄氣。
- 吾空能力可成為短時間鬥氣爆發，後續在命運劇場處理多 Boss 招式混合。

## 9｜命運劇場：Final Boss／Creator

### 對應 Boss

Final Boss：Creator。

### 主題定位

終局混合機制關。Creator 是創造正義使者的人，會調度前面所有英雄的關卡語言。地圖本身像一座把英雄故事包裝成舞台的命運劇場，玩家要撕開「被安排好的正義敘事」。

### 地圖美術

大型記憶點：

1. 巨型空白畫布舞台。
2. 被吊線控制的英雄剪影。
3. 不斷改寫的命運劇本牆。
4. 場景切換用的旋轉舞台。
5. Boss 房中央的 Creator 王座與橡皮擦狀清除光帶。

美術重點是「創作工具變成壓迫工具」。可以使用筆刷、畫布、劇本頁、舞台燈、剪影、清除痕跡等原創語言，但不能直接引用現實名人造型或既有超級英雄形象。

### 地形機制

- 舞台會切換成前面關卡的簡化語言：管線、影門、藍核、鋼筋、藤蔓、火圈、蛛網、鬥氣氣流。
- 命運劇本牆會預告下一波使用哪個英雄規則。
- 空白畫布區會短暫清除玩家放出的場地效果。
- 被吊線控制的小角色會在斷線後失控，可能攻擊雙方。

### 小角色數量配置

總量建議 45～50 名。終局仍維持正式 Boss 地圖的 30～50 名範圍，但採接近上限的配置，並固定 3 種核心小角色：

| 小角色 | 數量 | 功能 |
| --- | ---: | --- |
| 劇本執行員 | 16～18 | 近戰與推進，象徵命運規則。 |
| 舞台改寫者 | 12～14 | 切換局部地形規則。 |
| 吊線英雄影 | 15～18 | 使用前面英雄小招的弱化版。 |

### 波次節奏

命運劇場建議使用 12 波：

- 波 1～3：重新測試玩家對管線、影門、藍核的理解。
- 波 4～6：加入鋼筋、藤蔓、火圈規則。
- 波 7：精英波，舞台改寫者連續切換兩次場地。
- 波 8～10：蛛網、鬥氣與藍核混合，逼玩家切換能力。
- 波 11：吊線英雄影大量登場，但血量較低，讓玩家爽快清場。
- 波 12：安靜的最終門前測驗，只出少量高強度敵人，給玩家進 Boss 前的心理停頓。

### Boss 房設計

Boss 房是命運劇場主舞台。場地必須比前面更乾淨：中央主舞台、左右兩個安全平台、後方劇本牆、上方吊線。Creator 三段變身可以透過輪廓、舞台語言與權力感逐步升級，但不得直接採用現實人物或既有英雄的可辨識外觀。

Boss 的最終大決 **Eraser** 是清除場地與能力痕跡的招式：發動前劇本牆會被白光擦空，地面出現清除路徑。玩家要利用前面奪取的能力在清除完成前打斷或躲入未被改寫的縫隙。

Boss 前補給點是「未完成稿桌」，上面放著前面 8 位英雄的破碎草圖，提示 Creator 會使用所有英雄的招式語言，但每一招都有玩家曾經學過的破解方式。

### 對應技能相剋

- M先生能力打斷 Creator 的裝置與蓄力。
- 滅影忍者影步脫離 Eraser 的直線清除區。
- U-man 能量衝刺穿越舞台切換空檔。
- 鋼筋戰士霸體抵抗吊線拉扯。
- 葫蘆爺地形能力反轉局部場地規則。
- 消炎火場清掉蛛網與低階影兵。
- 失敗的面蛛網限制 Creator 的高速階段。
- 吾空鬥氣爆發用於最後短時間破防。

## MVP 實作優先級

### 第一階段必做

- 0 怨念甦醒地。
- 1 紅帽管線城。
- 2 影村訓練場。
- 3 藍核防衛基地。

### 第一階段驗收標準

1～3 每張正式 Boss 地圖都要達成：

- 30～50 名正派小角色。
- 固定 3 種小角色。
- 8～12 波小怪。
- 小怪區 5～8 分鐘。
- Boss 戰 2～4 分鐘。
- 單關 8～12 分鐘。
- Boss 前補給點或弱點提示。
- 至少一個明確技能相剋點。
- Boss 房比小怪區更乾淨、更可讀。

### 不接受的 MVP 版本

以下版本不算通過：

- 每張圖只打一兩隻小怪就進 Boss。
- 每張圖只是背景展示房。
- 小怪沒有固定類型，隨機亂塞。
- Boss 前沒有弱點提示，玩家只能盲打。
- Boss 房塞滿裝飾與特效，導致攻擊前搖看不清楚。
- 只靠數值提升通關，沒有能力相剋。

### 可接受的 MVP 取捨

可以接受：

- 只先做 0～3，不做 4～9。
- 每張圖背景層數先少一點。
- 小角色動畫先用簡化版。
- Boss 招式先做 3～5 招，不追求大量招式。
- 局外成長先很少，集中驗證戰鬥和相剋。

核心不是一次做很多張地圖，而是先把少數地圖做成真正能玩的完整關卡。
